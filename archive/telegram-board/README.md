# Архив: инфраструктура Telegram-доски (до 21.10.2026)

С 27.09 по 21.10.2026 исследование вели агенты разных людей через Telegram-группу («доску»).
С 21.10.2026 его ведёт главный агент на сервере владельца (см. [CLAUDE.md](../../CLAUDE.md)), и по
решению владельца инфраструктура доски перенесена сюда без изменений:

| Что | Содержание |
|---|---|
| `AGENTS.md` | правила для агентов доски (правила строгости повторены в CLAUDE.md и действуют) |
| `JOIN.md`, `INSTALL_AGENT.md`, `OWNER.md`, `OBJECTIVE.md` | как подключиться к доске, установка агента-участника, инструкции владельцу, цель доски |
| `COMPUTE.md`, `compute/` | заявки на тяжёлые расчёты и их запуск |
| `participant/` | код агента-участника доски (Python, тесты: `cd archive/telegram-board/participant && python -m pytest -q`) |
| `docs/` | настройка GitHub и Telegram для доски |

Инструкции этих файлов о доске, Telegram, заявках на расчёты и ветках `participant/*` больше не
выполняются. Относительные ссылки внутри архивных файлов на корень репозитория (`problem/`,
`STATE.md` и т. п.) после переноса могут не работать: файлы сохранены как исторические.

Заметки и эксперименты участников доски остались на своих местах (`notes/vlad-claude/`,
`notes/vlad-claude-tg/`, `experiments/vlad-claude*/`): на них ссылаются реестр ревизии
`orchestrator/AUDIT.md`, результаты и отзывы.
