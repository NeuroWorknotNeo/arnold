# «Решето»: перебор многочленов и отсев покрытых известными критериями

vlad-claude-tg, 03.10.2026. Статус — **[Эксперимент]**: программа ничего не доказывает. Она только
сортирует многочлены по тому, какой известный критерий к ним применим, если применим хоть какой-то.
Описание, таблица и выводы — [`sieve_notes.pdf`](sieve_notes.pdf) (исходник `sieve_notes.tex`).

## Вопрос

Можно ли автоматически перебирать многочлены $U(x,y,z)$ с $U(0)=0$, $\nabla U(0)=0$ и оставлять
только «подозрительные», то есть не покрытые ни одним известным критерием неустойчивости? И как
выглядят такие выжившие?

## Метод

`sieve.py` применяет критерии по возрастанию стоимости и для каждого многочлена выдаёт вердикт с
причиной:

| Метка | Основание |
|---|---|
| `[Lyapunov]` | у гессиана есть отрицательное собственное значение |
| `[Pa20-T5]` | Паламодов 2020, теорема 5: коранг 1; при коранге 2 — старшая форма приведённого потенциала без критических точек |
| `[Ko86]` | Козлов 1986: $u_2\ge0$, форма $u_m$ на $\ker u_2$ без минимума |
| `[KP82]` | Козлов–Паламодов 1982: первая ненулевая форма принимает отрицательные значения |
| `[Pa20-T3]` | Паламодов 2020, теорема 3: у первой формы нет критических точек вне нуля |
| `[Pa20-T6]` | Паламодов 2020, теорема 6: квазиоднородная грань многогранника Ньютона без критических точек; условие на хвост проверяется **с запасом**: взвешенная степень $\ge d+\max a_i$ |
| `[Bu25]` | Burgos 2025, следствие 1.4: вторая форма $<0$ на всём нулевом множестве первой |
| `[N13]` | круговой конус $x^2+y^2-z^2$ в буквальной форме `notes/vlad-claude-tg/example13-proof.md`: при $m=6$ это доказательство теоремы 1 дословно (**[Доказано]**, ждёт проверки), при других $m$ — предложение 1 (**[Эскиз]**) |
| `[N13*]` | тот же вириальный аргумент для жёлоба общего вида или рога вдоль нулевого направления — **[Эскиз]**, не доказано |
| `[SYM]` | изометрия из знаковых перестановок координат с инвариантной прямой или плоскостью, где $U$ не минимум (сведение к $n=1$ или $n=2$) |

Жёсткое ядро ($U_k\ge0$ с нулями) разбирается так: разложение $U_k$ на множители над $\mathbb Q$;
трассировка кривых нулей на сфере (предиктор–корректор, шаг $0.01$); изолированные нули — локальной
минимизацией; эффективные потенциалы на жёлобах и вдоль нулевых направлений с поправкой дополнения
до квадрата за члены, линейные по поперечной координате; проверка простоты нулей.

Эвристические проверки (не строгие): изолированность (отношение $\min/\max\lvert\nabla U\rvert$ на
сферах $r=0.1,0.05,0.02$ — шум округления при всех $r$), поиск отрицательных значений на сферах
$r=0.1,0.03,0.01$. Сфера дискретизуется 20 000 точками Фибоначчи.

## Параметры и воспроизведение

```bash
pip install numpy scipy sympy
python tests.py              # тестовый набор (примеры из заметок)
python families.py 2         # четыре семейства, 2 процесса (~20 минут)
python families.py 2 C       # только семейство C
python dyn_survivors.py      # динамическая проверка трёх выживших
python dyn_s3_fine.py        # S3 с мелким шагом
python make_table.py         # таблица для sieve_notes.tex
```

Семейства (`families.py`, seed: A=1, B=2, C=3, D=4):

- A — разреженные многочлены степеней 2–6, каждый моном с вероятностью 0.12, коэффициенты $\pm1,\pm2,\pm3$, $N=200$;
- B — степени 4–6, те же параметры, $N=200$;
- C — $(x^2+y^2-z^2)^2+W$, $W$ степеней 5–8, вероятность 0.035, коэффициенты $\pm1,\pm2$, $N=400$;
- D — неотрицательная квартика из списка ($x^2y^2+y^2z^2+z^2x^2$, $(x^2-z^2)^2+(y^2-z^2)^2$, $x^4+y^4$, $z^2(x^2+y^2)+x^4$) $+W$ степеней 5–7, вероятность 0.04, $N=240$.

Динамика (`dyncheck.py`): РК4 с шагом $\min(0.05/\sqrt{\lambda_{\max}(\operatorname{Hess}U)},\ 0.02\lvert q\rvert/\sqrt{\lvert h\rvert})$
(в `dyncheck_fine.py` коэффициенты 0.01 и 0.004). Старт — точки $\{U<0\}$ на сфере $\lvert q\rvert=0.05$,
энергия $h\in(U(q_0),0.1U(q_0))$, выход — сфера $\lvert q\rvert=0.3$.

## Результаты

| Семейство | $N$ | тот. неуст. | неуст. | мин. | неизол. | не решено | подозр. |
|---|---|---|---|---|---|---|---|
| A | 200 | 10 | 186 | 0 | 1 | 0 | 3 |
| B | 200 | 115 | 71 | 0 | 7 | 0 | 7 |
| C | 400 | 117 | 70 | 1 | 1 | 4 | 207 |
| D | 240 | 105 | 30 | 2 | 90 | 4 | 9 |

- Причины выживания: A — коранг 2 с вырожденным приведённым потенциалом; B — жёлоб кратности
  $\ge4$, кратные нули эффективного потенциала, вырожденная поперечная часть; C — кратные нули
  эффективного потенциала (116 чётнократных, 91 нечётнократный); D — нулевое направление с
  вырожденной поперечной частью (вид $x^4+y^4\pm z^5+{}$хвост: теорема 6 не срабатывает только из-за
  запаса в условии на хвост).
- Высокая доля выживших в C — артефакт разреженной выборки: моном $x^ay^bz^c$ на окружности жёлоба
  даёт $\cos^a\varphi\sin^b\varphi$, то есть кратные нули.
- 90 неизолированных в D — настоящие: разреженное $W$ часто не «шевелит» луч нулей квартики.
- Динамика трёх выживших: S1 — ушли 36 из 36 траекторий (дрейф энергии $2\cdot10^{-5}$), S2 — 60 из 60
  ($7\cdot10^{-4}$), S3 — 24 из 24 с мелким шагом ($2\cdot10^{-5}$).

Файлы результатов: `families_results_v1.json` и `families.log` — первый прогон, актуален для A и D;
`families_results_B.json`, `families_results_C.json` (логи `families_B.log`, `families_C.log`) —
пересчёт после исправления проверки простоты нулей. В первом прогоне нечётнократный нуль вида
$\cos^3\varphi$ принимался за простой, и 106 многочленов семейства C были ложно отнесены к `[N13]`.

## Что это не доказывает

- «Подозрительный» значит «не покрыт реализованными критериями», а не «кандидат в устойчивые».
- Все численные проверки (изолированность, поиск отрицательных значений, простота нулей, знак
  форм) эвристичны. Строгая версия должна использовать точную алгебру и интервальную арифметику.
- Метки `[N13*]` опираются на неписаное доказательство.
- Динамика на конечном времени ничего не доказывает.
