# Покрытие трудных примеров n = 3 принятыми теоремами 007–014 (и условно: 015, складки)

Статус: **[Эксперимент]** — классификация. Это проверка *условий теорем* на конкретных многочленах (точная арифметика sympy/Singular там, где указано;
в остальных местах численно с явной пометкой). **Ничто здесь не доказывает неустойчивость ни одного из примеров и ничего не доказывает про задачу (A) в целом.**
Утверждение «пример покрыт теоремой T» значит только «гипотезы T проверены (точно/численно, как указано), следовательно *по теореме T*, принятой агентами-рецензентами,
у примера есть асимптотическая траектория». Правильность самих теорем не проверялась. Теоремы 007–014 — принятые (проверены рецензентами, ждут человека);
015 (мастер-теорема MT, теорема H) и записка о складках (`notes/prover/2026-10-21-fold.md`, теорема C_Γ, предложение W″) — **не приняты** и вынесены в отдельную колонку.

## Вопрос

Для каждого трудного примера n = 3 из полигонов N2 (`2026-10-21-zoo`, 24 + 3 калибровки), N3 (`valleys`), N4 (`classK`), N5 (`frontier`, 17) определить,
покрыт ли он принятыми теоремами (проверить их условия на примере), и собрать таблицу покрытия; непокрытые сгруппировать по причине.

**Главные наблюдения** (подробнее — ниже и в `details.md`):

1. Все 27 примеров N2 покрыты принятыми теоремами (22 из 27 — теоремой M [010]; остальные — Q [012], M′ [014]/N [011], локальной K1 [008]). Заметки N2 и N5 сопоставляли примеры только с критериями и теоремами, доступными на момент расчёта
   (N2 — с известными критериями и теоремой B; N5 — с классами 008–010 и заметками), поэтому называли «непокрытыми» 19 + 17 примеров; это не противоречит нынешнему результату.
2. Из 17 примеров N5 непокрыты **2** (A2, V4), ещё **4** (D1–D4) покрываются только условной мастер-теоремой MT [015].
3. Три примера N5 (B3b, V1, V2) покрыты теоремой S [013] (полярный κ-приём) только с **численной** проверкой неравенств (S1)–(S3); строгого вывода неравенств здесь нет.
4. Пример B2 (касп + линейная сила) не покрывается ни X′, ни M, но у него есть **мелкий овраг на антиподальном листе конуса** (u_7 нечётна): там G имеет
   невырожденный отрицательный минимум с G″ + 7G > 0, и применима локальная теорема K1 [008] (независимо подтверждено прямой минимизацией U на сферах: U/r⁷ → −0.066725 при r → 0, `b2_check.py`). Остальные «глубокие» овраги N5 при этом остаются в особой точке.
   Общее наблюдение: *теоремы K, N, W локальны*, так что надо проверять **все** дуги Σ и все точки, а не только самый глубокий овраг (N3/N5 считали только самый глубокий).
5. V1 и V2 (два сливающихся/разрешённых подоврага): прямая карта (утверждения Q/E, C′, SV из [012]) не работает, но подовраги — нули **однородных** форм
   xy − z², x²y − xz² − z³ ⇒ в **полярной** карте они неподвижны, и поле ξ = (3θ_y − θ_z², θ_z) сохраняет оба точно; теорема S [013] с допуском χ(r) ∼ r^{2/9} (r^{2/13}) закрывает оба
   (численно). У V4 подовраги неоднородны (профиль в карте весов (2, 3), Q = AB с неоднородными A, B), и этого нет.
6. Кольца D1–D4 (G ≡ const на C1, касание с C2): принятые теоремы не работают (кольцо плоское, на концах — узлы касания), но статические условия MT [015] выполняются
   численно — плоское кольцо MT не мешает (траектория не обязана выбирать точку кольца).

## Метод

Для каждого примера (скрипты — в этой папке, запуск ниже):

1. **Базовые данные** (`basic.py`): m, u_m, явная сумма квадратов u_m = Σ c_i p_i² (`expand`, точно), точный свидетель U < 0 (младший коэффициент U вдоль явной кривой), изолированность 0
   (из логов полигонов: конечное число Милнора или насыщение в Singular над ℚ; **не** пересчитывалась, кроме перезапуска трёх зависших расчётов — раздел «Фоновые расчёты»).
2. **Строение Σ = {u_m = 0} ∩ S²** (`sigma.py`, Singular `minAssGTZ` над ℚ + sympy; точно): компоненты (точки/конусы над кривыми), гладкость конуса ((f, ∇f) m-примарен?),
   кратность f в u_m = f^k g, нули g на кривой (точки, где нормальная кратность падает/растёт; вещественные), ранг и положительная определённость гессиана D²u_m|ω^⊥ в точках, пересечения/касания ветвей (длина `vdim` в карте z = 1).
3. **Условия теорем**: перечислены в `matrix.md` (14 столбцов). Для теорем с эффективным потенциалом G (K0, K1, K2, N, Mb/Mc/Md) — `curves_frontier.py` (модуль kfib/classK, ряды точно), `cusp_G.py` и `g1.py`
   (случай j = m + 1: G = u_{m+1}|Σ, критические точки — вещественные корни числителя G′ точно, значения G, G″ — mpmath 40 знаков), для zoo — результаты N4 (`classK/summary.json`) и `kextra.py` для P2, H1, H2, не вошедших в N4.
   Для «утверждения Q/следствия E» [012] — `direct_chart.py`, `vgroup.py`: уровни мономов Û(s, w) = U(s^N, γ̃(s) + w) относительно весов c (точно, 4^{−1/3} как корень 4K³ = 1), грань F_0, Q, гессиан/взвешенные главные части. Для X′ [013] — `xprime.py`
   (символьно). Для M′ [014] и N [011] у M1, M2 — `newton_equator.py` (многоугольник Ньютона, Φ0, тождество для Ũ, условия (R)/(UR)).
4. Численные проверки неравенств теоремы S [013] (`s_check.py`, `s_check_V.py`, контроль случайными точками `s_random.py`) и статических условий MT [015] для колец (`mt_check_ring.py`): сетки в float64, адаптированные к тонким
   подоврагам; печатается отношение минимума к r^e, ограниченность которого и есть существование χ(r) → 0. **Это не доказательство неравенств.**

Обозначения в матрице: ✓ — условия теоремы подтверждены (точно либо с знаком алгебраического числа по 30–50 знакам); ✓\* — условия подтверждены только численно на сетке; ✗ — условие нарушено (причина в `details.md`); — — теорема неприменима по строению
(нет кривых/точек нужного вида; не нужна); ? — не проверялось.

## Непокрытые примеры и их причины (граница метода)

**Не покрыты принятыми теоремами: 2 примера. Условно (только MT [015]): 4.**

### Группа I — дно в точке падения нормальной кратности, где G определена, но условия данных нарушены: **f:A2**

Σ = экватор, нормальная кратность 2 → 4 в ±e_x (u_4 = z²(y² + z²), g = y² + z² обращается в 0 в ±e_x). Эффективный потенциал
G(φ) = −cos⁶φ/8 + sin⁶φ + cos⁴φ sin²φ (j = 6) аналитичен и имеет невырожденный минимум −1/8 при φ = 0, π; **но** именно там H = D²u_4(n,n) = 2 sin²φ = 0, условие (S)
теорем K1, K2, N, W и Mb нарушено (поправка следующего порядка ∼ r²/(16 φ⁴) не ограничена); других отрицательных минимумов G нет (критические точки: максимумы G = 1 при t = ±1, минимумы только при t = 0, ∞).
M, M′ неприменимы (постоянная кратность нарушена). Прямая карта (утверждение Q, 2U, C′): дно по экватору имеет ширину ∝ r (c = 0.995, N5), а [012] требует весов c_i > 1 и коэрцитивности в окне |b| < r_1
(при c_y > 1 окно слишком узко и 𝒲 в нём почти не зависит от b_y — (U3) нарушено). Полярная теорема S [013]: (S3) W(r, 0) = 1/4 + a_0 в базовой точке e_x, а на любой другой точке экватора
a_0 ≤ −u_6|_Σ ≤ 0, т. е. условие a_0 > 0 невозможно. Условно MT: см. ниже.
*Что нужно*: теорема о дне в точке падения кратности с двумя несоизмеримыми масштабами (по углу ∼ r^{1/3}, по нормали ∼ r^{5/3}); критическая точка по нормали ∼ (r θ)^{1/3} не аналитична по θ в θ = 0.

### Группа II — изолированный вырожденный нуль u_m, подовраги неоднородны (плохая ориентация): **f:V4**

Σ = {±e_x}, D²u_m = 0. Точная реализация профиля §6.2 [009] с весами c = (2, 3) (b_1 = y/x² шире, b_2 = z/x³ уже): (Q1), (Q2) выполнены (Q = A·B, F_0(0) = −1),
но Q_4 = w_1⁴ ⇒ Q_d(0, 1) = 0 при c_1 < c_2, следствие E неприменимо; SV неприменимо (подовраги касаются *узкой* оси); по [009, пр. 6.2] нет липшицева поля Эйлера с ξ_1 = f(b_1) — условие (T) теоремы 2U недостижимо.
В полярной карте (теорема S) подовраги b_1 = b_2² и b_1 = b_2² + b_2³ в переменных θ имеют вид θ_y = θ_z²/r³ и т. д. — зависят от r, фиксированное поле ξ(θ) не может быть касательным к ним (в отличие от V1, V2 с однородными формами).
Изолированность 0 — точно (двойное насыщение, 959 с). *Что нужно*: поле Эйлера, зависящее от s, либо иная конструкция — вне принятых теорем.

### Группа III — плоское кольцо G ≡ const на компоненте Σ с узлами касания: **f:D1, D2, D3, D4** — *условно* покрыты MT [015]

Σ = C1 ∪ C2 (коники x² + y² = z² и x²/2 + y² = z²), касание порядка 2 в четырёх точках (0, ±1, ±1)/√2; G = u_9|_Σ ≡ −2^{−9/2} на C1 (D3, D4 — с точно нулевой нормальной силой), на C2 минимум G только в узлах.
M, M′ неприменимы (Σ не многообразие), K1/K2/N/W — нет дуги с G″ > 0 (на кольце G ≡ const, (W1) — нуль 𝒲 неизолирован), S — (S1) нарушено вдоль кольца (W = O(r) при |θ| ∼ θ_0), C [014] — P(θ, e) ≥ q_0(|e|) нарушено в узлах
(кратность 2 → 4). Дно выбирается следующим порядком (D1: y z⁹ — узел, N5: сдвиг ∼ r^{1/3}; D3: x·P — гладкая точка кольца; D4: y·P — узел). MT от выбора не зависит (см. раздел «Условно»).


## Условно (015): что проверено

MT [015] — это редукция (задача A при n = 3 сведена к статической гипотезе SH₃), все её условия *статические*: стенки (W), дно (B), пол (F), неравенство Эйлера (E) для относительного избытка 𝒲 = s^{−β}U∘Ψ + a_0 и

## Что расчёт показывает и чего не доказывает

* Показывает: для каждого из 44 примеров — какие *гипотезы* какой принятой теоремы выполняются (точно/численно, как отмечено), а где и какое условие нарушено.
* **Не доказывает** неустойчивость ни одного примера: «покрыт» означает «по принятой теореме есть асимптотическая траектория» при условии, что теорема верна и её условия проверены правильно; принятые теоремы проверены агентами, не человеком.
* Условия, проверенные **численно** (S для B3b, V1, V2; MT для D1–D4), не заменяют строгого вывода неравенств; сетка может пропустить узкую область (контроль случайными точками для S показал совпадение, для MT не делался).
* Знаки алгебраических чисел (G, G″ в минимумах, гессианы с 4^{−1/3}) определены численно по 30–50 знакам при точном алгебраическом происхождении чисел; это не формальное доказательство знака, но практически надёжно.
* Столбцы K1/K2/подслучаи M для zoo берутся из результатов N4 (`classK/summary.json`), которые я не пересчитывал, кроме P2, H1, H2 (`kextra.py`); для C3 (эллипс, нечётное j) G не вычислялось (M покрывает независимо).
* Полнота поиска оврагов/дуг: проверены все компоненты Σ и обе половины конуса, но для особых точек Σ (касп, касание) «нет подходящей дуги» опирается на сам список критических точек G, который
  точен лишь для случая j = m + 1 (B1–B4, D, B3, B3b); для A1–A3, E1 — ряды kfib до порядка m + 4.
* Утверждения вроде «у A2 нет подходящей карты» — отрицательные: они означают лишь, что условия *известных* теорем нарушены и мои попытки подобрать карту/поле не удались; существование асимптотической траектории у A2, V4 этим не опровергается.
* Изолированность 0 у V3, D3, D4 не сертифицирована (расчёт над ℚ не завершается); у остальных — точно по логам полигонов.
