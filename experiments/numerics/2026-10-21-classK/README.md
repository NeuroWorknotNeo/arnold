## Метод

1. **Σ и условие Морса–Ботта (символьно, точно).** u_m берётся из `catalog.py` полигона; тождество u_m = Σ c_i p_i²
   (сертификат SOS каталога) проверено точно для всех 22 примеров (`sos_certificate_ok` в `out/*.json`), поэтому u_m ≥ 0,
   а Σ = {p_i = 0}∩S². Круговые/эллиптические конусы параметризованы рационально (параметр t, см. `comps.py`),
   большие круги — тоже; для T1 (кубический конус C = y²z−x³−xz²) параметризации нет, критические точки найдены через
   результант (см. п. 3). Гладкость конуса {f=0}: базис Грёбнера идеала (f, ∇f) нульмерен и однороден ⇒ ∇f ≠ 0 вне нуля над ℂ
   (`sigma_checks.txt`). Условие Морса–Ботт: H(t) = D²u_m(p(t))(ν,ν) > 0 при всех вещественных t (нули H изолируются точно;
   ν = ∇f(p) ∈ N_ω, масштаб ν не влияет на R); для точечных Σ — положительная определённость H на p^⊥ (точные ведущие
   миноры). Когда u_m = z⁴ или x⁴+y⁴, D²u_m ≡ 0 на Σ — не Морс–Ботт (`sigma_checks.txt`).
2. **Редуцированная функция (лемма K1) — точно.** Модуль `kfib.py`: φ(s,Y) = Σ s^{k−m} u_k(p + Yν), критическая точка
   Y*(s) — степенной ряд, решается итерацией Ньютона по рядам над полем рациональных функций от t (sympy.cancel), затем
   R(s) = φ(s,Y*(s)) = Σ s^i g^p_{m+i}. Нормировка на единичный ω: g_k(ω) = g^p_k/|p|^k (R не зависит от масштаба p/ν).
   Считаются g_{m+1..m+4}; j = первый ненулевой (точное сравнение с нулём после сокращения). Модуль воспроизводит формулы
   записки: K3: g_5 = √2cosφ/8, g_6 = −9cos²φ/512; K2: g_6 = 1/16+cosφ/8+sin2φ/16 (`test_fibre.txt`). Это та же
   конструкция, что в `reduced.py` prover, но реализована заново (независимо) и обобщена на любые параметризации и на точки.
3. **Критические точки G.** Числитель G′(t) раскладывается на свободные от квадратов множители с кратностями (sympy.sqf_list),
   вещественные корни — точная изоляция (real_roots), затем значения G, G″ (по натуральному параметру: G″ = G_tt/|ω_t|²,
   |ω_t|² рационально), G″+jG — mpmath, 25–30 знаков. Точка t = ∞ рассматривается в карте τ = 1/t. Кратность корня G′ = 1 ⇔
   невырожденный экстремум; чётная кратность ⇒ перегиб; нечётная ≥ 3 ⇒ вырожденный экстремум. Для T1: G = u_8|Σ точно
   (u_7 = 0 ⇒ g_7 = 0 и b_1 = 0 ⇒ g_8 = u_8|Σ); критические точки на Σ — из C = 0 и det[∇u_8, ∇C, ω] = 0 (результант по y,
   многочлен степени 29 от x; корни точно), G″ = D²u_8(T,T) − 8G + k⟨∇u_8,n⟩, k = −Tᵀ(D²C)T/|∇C|.
4. **Независимые проверки (численно, mpmath dps 60), не используют ряд `kfib`:** `verify.txt` — для каждого отрицательного
   минимума G (всех кривых и точек) вычислен min_η U(sω + ην) прямым Ньютоном при s = 10⁻²…10⁻⁵: отношение к s^j G стремится
   к 1 с ошибкой O(s) (например, K2: 1.0000017, 1.0, 1.0, 1.0; A1: 0.9970, 0.99970, 0.99997, 0.999997). `gpp_check.txt`:
   G″ при j = m+1 (K3, A5, Z1, S1) по независимой формуле G″ = D²u_j(T,T) − jG + k⟨∇u_j,n⟩ совпадает с G″ из ряда до
   12 знаков. `verify_extra.txt`: A4 (g_7(ω₀) = −√2/16, отношение 1.0004, 1.00004, …), D1 (G ≡ −1/16 в четырёх точках Σ₊).
   Совпадение ρ = (G″+jG)/(−jG) с ρ из valleys (там H_plane получен независимо прямым расчётом профиля среза) — ещё одна
   независимая проверка G″.
5. **Сдвиг η\*** (`shift_flags.txt`): j и G определены через критическую точку в слое, а не ограничением u_k|Σ. Сдвиг существенен в D1 (наивное
   j_naive = 6 с G_naive = z²m² ≥ 0, правильное j = 8 с G ≡ −1/16), в D2 и F1 (j совпадает, G ≠ u_j|Σ; D2: G совпадает с G
   примера 13 точно), а также формально в K3, A5, Z1, S1, где b_1 = ∂_ν u_{m+1} ≢ 0, но j = m+1 и G = u_j|Σ.

## Что показал эксперимент (по примерам)

* **K⁰: P3, P4** (Σ конечно, все точки Морс–Ботт, H ≻ 0). P3: 8 точек; в четырёх из них j = 5: g_5 = −2√3/27 < 0 в
  (−1,±1,1)/√3 (теорема K0) и g_5 = +2√3/27 в (1,±1,−1)/√3; в остальных четырёх (1,±1,1), (−1,±1,−1) g_5 = 0 и j = 6,
  g_6 = −17/432 < 0 (в g_6 входит поправка сдвига). P4: g_5(−e_x) = g_5(−e_y) = −1 (K0), g_5(+e_x) = g_5(+e_y) = +1; ±e_z: j = 6,
  g_6 = +1 > 0. Так как Σ конечно, а U изолирована (по zoo: μ = 33 и 31), к P3 и P4 применимо **следствие K0′** (трихотомия,
  (A) решена в классе); асимптотическая траектория по K0 — в направлении (−1,±1,1) у P3 и −e_x, −e_y у P4.
* **K¹ с теоремой K1:** A3, C1, D2, F1, T1, Z1 — G имеет невырожденный отрицательный минимум с G″+jG > 0 (A3: 0.0914,
  C1: 0.399, D2: 0.0502, F1: 2.299, T1: 0.933, Z1: 0.209). Запас у A3, D2 и Z1 мал (ρ = 0.117, 0.084, 0.038).
* **K¹, только K2:** A1 (G″+6G = −1.244), A2 (−1.386), A5 (−1.345), A7 (−0.0748), C2 (−0.0854) — у них G″ > 0, но G″+jG < 0,
  так что декартова карта теоремы K1 не работает, нужна поворачивающаяся карта теоремы K2 (опирается на новую теорему 2′).
  Двойные/тройные нули G в A1, A2, A3, A5 класса не меняют: подходящий минимум G отрицателен и невырожден.
* **A4 (§10.2 п.3, каскад).** G = t²(t²+t+1)/(4(t²+1)²) ≥ 0 на Σ₊ с двойным нулём в ω₀ = (1,0,1)/√2 (G″ = 0.25); на Σ₋ тоже
  G ≥ 0 с двойным нулём в −ω₀ (t = ∞), но там g_7 = +√2/16 > 0. Отрицательные значения только в следующем порядке:
  g_7 ≡ −√2/16 на Σ₊ (g_7(ω₀) = −(1/√2)⁷ = −0.0884; min_η U/s⁷ → g_7(ω₀), `verify_extra.txt`), а G″ > 0 даёт угловой масштаб
  s^{1/2} (valleys: c = (3/2, 5/2)). Условие K3 (G(ω*) < 0) не выполнено.
* **D1 (§10.2 п.1).** После сдвига g_5 = g_6 = g_7 = 0, G = g_8 ≡ −1/16 (константа) на Σ±: точный результат. Следующие члены
  непостоянны: g_9 = −√2(t²−1)(t²+2t+2)/(8(t²+1)²) на Σ₊ (min −0.2410), на Σ₋ min −0.3842 при t = −6.0197 — это в точности
  направление дна из valleys (расстояние 8·10⁻⁷). Наивное ограничение u_6|Σ = z²m² ≥ 0 дало бы совсем другую картину.
* **M1, M2, P1, K1 (§10.2 п.4).** D²u_m ≡ 0 на Σ (u_4 = z⁴ или x⁴+y⁴): порядок вырождения 4. Лемма K1 (аналитическая критическая
  точка в слое) здесь не применима; G не определён. Согласованность: нормальный вес c = (j−m+4)/4 = β/4 совпадает с
  valleys (K1, P1: 3/2; M1: 5/4 при β=5; M2: 4/3 при β=16/3) — это согласие чисел, а не проверка теоремы.
* **S1.** Σ = два больших круга x = ±y, пересекающиеся в ±e_z; там H = 32(t²−2)² = 0, так что Морс–Ботт нарушен ровно в
  двух точках. По определению (K1) Σ должно быть гладким — S1 вне K формально (§10.2 п.5). Но G на открытых дугах определён:
  j = 5, G = −√2(t²−2)⁴(3t²−8t−6)/(8(t²+2)⁵) на круге x = y; минимум −0.5730 при ω = (−0.6974,−0.6974,−0.1651),
  G″+5G = 0.321 > 0. Если принять §1 п.3 записки («условия нужны только около ω*»), то условия теоремы K1 выполнены
  локально. Это чтение записки, оно не проверено мной по доказательству (лемма K3 и теорема K1 формулируются для дуги
  Σ₀ около ω*).
* Пункт §10.2 п.2 (вырожденный изолированный минимум G, G−G_min ∼ θ^{2p}, p ≥ 2) — среди примеров не встретился: все
  отрицательные локальные минимумы G невырождены (кратность нуля G′ = 1). Вырожденные экстремумы G встретились только у S1 в
  особых точках ±e_z (G ∼ θ⁴, там Σ особо, это не часть K).

## Чего это не доказывает и что не вычислено

* Ничего об устойчивости. Принадлежность классу K — лишь выполнение гипотез теорем; сами теоремы K0, K1, K2, теорема 2′ и
  лемма 2′ в записке помечены «ждёт рецензента» (K2 опирается на новую теорему 2′). Применимость K2 ≠ проверенное
  существование асимптотической траектории.
* Изолированность U не проверялась (она в zoo; в классе K она не нужна).
* Для M1, M2, P1, K1 (не Морс–Ботт) ряды R_ω и G не вычислялись (лемма K1 неприменима); для них — только факт нарушения
  Морса–Ботта.
* Для A4 разобран только первый шаг каскада (g_7(ω₀) < 0); полной картины «каскад ⇒ траектория» нет (это §10.2 п.3,
  [Гипотеза]). Для D1 вычислены g_9, g_10 (K = 6), но теории «G ≡ const» с поправкой нет (§10.2 п.1 — [Эскиз]).
* Считались g_{m+1..m+4}; во всех примерах j ≤ m+4 найден, так что усечение не мешало (D1: j = 8 = m+4, K=6 для следующих).
* T1: число компонент Σ не вычислялось численно; из вида кривой y² = x³+x (одна нечётная ветвь через бесконечно удалённую
  точку (0:1:0)) это одна замкнутая кривая на S² — рассуждение, не расчёт. Список критических точек G на Σ — из точного
  результанта: найдено два проективных критических значения (минимум −1.0573 и максимум 0.125 в (0,1,0)); на S² это четыре
  точки. Достаточно для вывода о K1 (минимум невырожден, G″+8G = 0.933 > 0).
* Тонкая оговорка по «минимумам G»: в таблице указан *глобальный* минимум G. Теоремам K1/K2 достаточно любого невырожденного
  локального минимума с G<0; у C2, A2, A7, A1, A5 других отрицательных минимумов нет, у S1 — есть второй (−0.0115 и ещё два
  на круге x=−y), они тоже подходят (G″+jG>0).
* Доказательство 2D-сходимости в (a=−G_min) и др. — по ряду до порядка s^{m+4}; остаточные члены R не оценивались.
  Проверка `verify.txt` подтверждает ведущий член численно, не строго.

## Параметры, воспроизведение

Все вычисления детерминированы (генератора случайных чисел нет, seed не нужен). Точность: символьные выкладки точные
(рациональная арифметика sympy), mpmath — 50–60 знаков (в таблицах выводится 25–30). Python 3.14, sympy, mpmath
(`~/venv/bin/python`). Время: порядка минуты на ядро на пример; всё вместе — несколько минут.

```
cd experiments/numerics/2026-10-21-classK
./run_all.sh                 # всё; пересобирает table_raw.md (таблица в README.md вставлена из него), details.md, summary.json, valleys_compare.json
python classk_analyze.py A1         # один пример: точный анализ компонент (out/A1.json)
python show.py A1            # краткая распечатка
```

Файлы: `kfib.py` — редукция в слое (точно); `comps.py` — параметризации Σ; `classk_analyze.py` — анализ компонент; `t1.py` — T1;
`d1_next.py` — следующие порядки D1; `sigma_checks.py`, `shift_flags.py` — проверки Σ и роли сдвига; `verify*.py`,
`gpp_check.py` — независимые проверки; `summarize.py`, `make_table.py`, `make_details.py` — сборка таблиц.
Данные valleys читаются из `../2026-10-21-valleys/summary.json` только для сравнения.
