# Дно оврагов для трудных примеров полигона (n = 3): глубина, поперечная структура, классификация для (GT3), стрельба назад

Статус: **[Эксперимент]**. Всё ниже — численное (mpmath, 60 знаков) и символьное свидетельство, а не доказательство.
Ничто здесь не доказывает неустойчивость ни одного примера и ничего не доказывает про задачу (A) в целом.
Отдельные выкладки помечены явно ([Эскиз], [Гипотеза]).

## Вопрос

Для 19 примеров полигона `experiments/numerics/2026-10-21-zoo/`, не покрытых известными критериями (A1–A5, A7, C1, C2, D1,
D2, F1, M1, M2, P1, P3, P4, Z1, S1, T1), и калибровок K1 = x⁴+y⁴−z⁶, K2 = пример 13, K3 = пример теоремы B найти:

1. «дно самого глубокого оврага» m(r) = min_{|q|=r} U(q) при r = 10⁻¹…10⁻⁶, показатель глубины β, направление дна ω(r)→ω∞,
   число оврагов одинаковой глубины;
2. поперечную структуру: гессиан U на сфере S_r в точке минимума, его собственные значения как функции r, вырожденность,
   поперечные масштабы (ширина {U < m/2});
3. классификацию (i) невырожденный поперечный минимум со степенными масштабами / (ii) вырожденный / (iii) несколько
   оврагов одинаковой глубины — по пригодности для достаточного условия (GT3) (`notes/prover/2026-10-21-gt3.md`, §5);
4. численно искать асимптотические траектории стрельбой назад от дна с энергией 0.

## Результат в нескольких строках

* Все 22 примера (19 + K1–K3): глубина — точная степень, β ∈ {5, 16/3, 6, 7, 8}; m(r) = −a r^β (1 + O(r^δ)), направление дна
  ω(r) сходится (ω−ω∞ ∼ r^p, p ≈ 0.4…2). Список a, β, ω∞ — в таблице.
* Невырожденное (по-сферному) поперечное дно со степенными масштабами (κ→const) у 16 из 19 (класс (i)); вырожденное квартичное
  дно (κ→0 степенно) у P1 и M1 (K1 — калибровка того же типа); плоское дно вдоль всей кривой — у D1 (в классе (ii)).
* **Новое наблюдение (важное для применения (GT3)).** Гессиан на сфере и гессиан в плоском срезе X = const (тот, что нужен в
  (V₁) при прямой/развёрнутой карте) для мягкого направления c = 1 различаются на β·a·r^(β−2):
  H_plane = λ_мягк/r^(β−2) − β a [Эскиз, вывод ниже; проверено прямым расчётом профиля в плоском срезе, `check_plane.txt`,
  совпадение до 5–6 цифр]. Для K2 получено 0.05024 — это число §6.3 заметки prover (там «запас» 0.40/8). **У A1, A2, A5, A7,
  C2 (и K3) H_plane < 0**, то есть условие (V₁) в карте развёртки конуса не выполнено, хотя дно по-сферному невырождено.
  У A3, A4, C1, D2, F1, S1, T1, Z1, M2, P3, P4: H_plane > 0 (или c > 1).
* **Стрельба назад сходится у всех 22 примеров и у всех проверенных дополнительных оврагов (ветвей: A1, A2, A3, D2, M1, M2×3, P4,
  S1, Z1×2; для D1 вторая ветвь не считалась)**, включая (ii) и случаи H_plane < 0
  (скорость сходимости предсказывается линеаризацией вдоль гомотетической траектории: см. §«Скорости сходимости»).
  Прямой прогон из предельного входа следует степенному закону r(t) ∼ t^(−2/(β−2)) до порога точности (ошибка энергии, r ≈ 10⁻³; подробнее в «Методе»).

## Метод

Код — в этой папке (см. «Файлы»); Python 3.14, mpmath 1.x (gmpy2), sympy, numpy; C (gcc) для интегратора.

**Дно (m(r), ω(r)).** Точность: `mp.dps = 60`. Минимум на сфере S_r — метод Ньютона на сфере (касательный базис,
риманов гессиан P r²∇²U P − r(w·∇U) P, критерий остановки: шаг < 10⁻³⁰ рад). Из-за узкого изогнутого дна (ширина ∼ r^c, c ≥ 1,
кривизна дна O(1)) обычный Ньютон идёт по дну крошечными шагами, поэтому для кривых Σ = {нулевое множество младшей формы u_m}
(из `catalog.py` полигона) использован **профильный метод**: Σ трассируется на сфере с шагом 0.025 рад, в каждой точке p(s) ∈ Σ
берётся минимум по поперечному смещению θ вдоль геодезической (старты θ = 0, ±r^{1/2…3}), затем у локальных минимумов
профиля — золотое сечение по s и полировка 2D-Ньютоном (`curves.py`). Для изолированных нулей (Σ — точки) — Ньютон из
сдвигов порядка r^{1…3} вокруг точек; на r ≥ 10^{−3.1} добавлены минимумы грубой сетки 1200×2400 (double). Радиусы:
r = 10^{−1, −1.5, …, −6} (11 штук). Сохраняются все локальные минимумы с U < 0 (сортировка по U), орбиты относительно точных
симметрий U (знаковые перестановки координат, найдены символьно) и ветви равной глубины.
**Контроль глобальности** (`check_global.py`, `check_global.txt`): на r = 0.1, 0.03, 0.01 найденный m(r) не больше минимума по
сетке 2400×4800 (double); CHECK!! ни разу не сработал. Для r < 0.01 сетка бесполезна (тонкие рога), там проверки нет
(см. «Чего это не доказывает»).

**Показатели.** β — наклон log|m| против log r по 7 последним радиусам (округлено до 1/6), a = |m|/r^β. Гессиан в
физических единицах: λ_i(r) = (риманов гессиан)/r², γ_i — наклон log λ_i. «Мягкое» направление — меньшее λ.

**Ширины.** w — ширина {U < m/2} (уровень f = 1/2; при слишком широком дне f = 1/10) вдоль собственного направления, в
физических единицах (длина дуги × r). Два способа: «прямая» ширина (по геодезической сферы из точки дна) и «профильная»
(минимум по поперечному смещению — следует за изогнутым дном). Для **жёсткого** направления верна прямая ширина, для
**мягкого** — профильная (прямая геодезическая выходит из изогнутого оврага: ширина вдоль желоба получалась r^{3/2}, а не r).
При совпадающих собственных значениях (K1, P4, M1) направления произвольны: сканируются 8 углов, мягкое = максимум профильной
ширины, жёсткое = минимум прямой ширины. c_i — показатель w_i ∼ r^{c_i}; из γ_i = β − 2c_i получается тот же c_i.
**κ_i = λ_i w_i²/(2 f |m|)** (безразмерная мера невырожденности: κ = 1 для чисто квадратичного дна). κ_i → const > 0 — класс (i);
κ_i ∼ r^{s}, s > 0 — вырожденное дно (чаша высшего порядка), (ii-a); если мягкая ширина не найдена и квадратичная оценка
ширины sqrt(|m|/(λ r²)) > 1 рад — дно плоское вдоль всей сферы, (ii-b).

**H_plane и ρ.** Пусть дно — луч ω∞ и мягкое направление e ⟂ ω∞ имеет c = 1. На сфере |q| = r точка q = r(cos θ ω + sin θ e)
имеет X = ⟨q, ω∞⟩ = r cos θ, а в плоском срезе X = const радиус растёт: |q|² = X² + Y². Поскольку U ≈ −a|q|^β вдоль дна,
d²U/dY²|_{X=const} = d²U/ds²|_{|q|=r} − β a r^{β−2}, т. е. **H_plane = λ_мягк/r^{β−2} − β a**, ρ = H_plane/(β a) [Эскиз; нужно
лишь U_η = 0 в точке дна]. Прямая проверка (`check_plane.py`): срез плоскостью ⟨q, ω∞⟩ = X = 10⁻⁴, профиль min_η U(Xω + y e + η ν),
вторая разность по y; сравнение со формулой — `check_plane.txt` (расхождения ≤ 6·10⁻⁵ отн.).

**Траектории** (`traj_run.py`, `traj_c.py`). Для r₀ = σ·f_k, σ = 0.05, f = 0.6, 0.4, 0.25, 0.15, 0.09, 0.055, 0.033, 0.02
(r₀ от 0.03 до 0.001): точка дна q₀ = r₀ ω(r₀) (ветвь, ближайшая к дну при r = 10⁻⁶; Ньютон из ближайшего
сохранённого радиуса), скорость вдоль касательной к кривой дна (конечная разность по r), |v| = sqrt(−2U(q₀)) (E = 0),
**обращённая** (поток интегрируется вперёд с v → −v, т. е. назад по времени) до сферы |q| = σ; состояние входа Z_k. Схема —
симплектическая композиция Йошида 6-го порядка из «прыжка лягушки», long double, шаг кусочно-постоянный: h = ε/√(4‖∇²U‖_F)
на сегментах r (r меняется ≤ в 1.25 раза), ε = 0.1; на границах сегментов симплектичность строго нарушается, но контролируется
дрейф энергии max|E − E₀|/(a r^β) (при стрельбе назад ≤ 2·10⁻⁹ для всех примеров, кроме D1 — 2·10⁻⁶; обычно 10⁻¹³–10⁻¹⁵). Если Z_k сходятся
(|Z_{k+1} − Z_k| убывает геометрически), предельное Z_∞ даёт траекторию, идущую вперёд к 0 (идея теоремы A заметки prover);
затем прямой прогон из последнего Z_k сравнивается с r_pred(t) = (σ^{−(β−2)/2} + ((β−2)/2) √(2a) t)^{−2/(β−2)}.
Важно: ошибка энергии при прямом прогоне (округление входа Z_k в double и усечение схемы при ε = 0.1) по абсолютной величине
примерно постоянна, а масштаб a r^β падает как r^β, поэтому |E − E₀|/(a r^β) растёт ∼ r^{−β} (у K1 при ε = 0.1: 4·10⁻³ при
r = 2.4·10⁻³, 0.9 при r = 10⁻³; при ε = 0.02 ошибка на ∼4 порядка меньше, проверено). Траектория «видна» только при r ≳ 10⁻³ (β = 6…8);
в таблице указан наименьший r, где |E − E₀|/(a r^β) < 10⁻². Это ограничение численное и не означает неустойчивость.

## Чего это не доказывает

* Ни один пример не доказан неустойчивым; сходимость входов стрельбы + согласие прямого прогона с r_pred — свидетельство
  существования асимптотической траектории, но не доказательство (нет оценок точек строгого выхода; r₀ ∈ [10⁻³, 3·10⁻²] —
  полтора десятичных порядка, 6–7 шагов геометрической сходимости; double в данных входа; прямой прогон виден лишь до r ≈ 10⁻³).
* Класс (i) — численное наблюдение степенных масштабов с невырожденным дном по 11 радиусам (r = 10⁻¹…10⁻⁶): оно не исключает
  логарифмических поправок и смены режима при r < 10⁻⁶. Это необходимое числовое условие для (V₁), но не проверка условий
  (Φ0)–(Φ3) и (F) для конкретной карты (в частности sup|s ∂_s F| → 0 не проверялось, кроме показателя поправок a(r)).
* Полнота поиска оврагов: профильный метод ищет вдоль Σ с поперечными старты до r^{1/2}…r³; тонкий рог вне такой трубки
  (или с шириной вдоль Σ, меньшей шага 0.025 между соседними минимумами профиля, но не видный как локальный минимум профиля)
  мог быть пропущен; независимая проверка (сетка) работает только при r ≥ 0.01.
* ρ получено при допущении «дно — луч ω∞ и c_мягк = 1»; для кривых оврагов (M2) формула H_plane приближённая (прямая проверка:
  0.0465 против 0.0438).
* Для рациональных значений показателей использованы округления (β до 1/6; c_i по наклону на 7 радиусах), при c_i, близких к
  граничным значениям, классификация (i-a)/(i-b) зависит от знака малой величины (A3: ρ = 0.12; Z1: 0.04; M2: 0.015; D2/K2: 0.08).
