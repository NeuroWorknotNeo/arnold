# «Полигон»: трудные тестовые потенциалы для случая (A), n = 3

Статус: **[Эксперимент]** (точные выкладки помечены явно). Ничего из этого не доказывает неустойчивость ни одного
из примеров и ничего не доказывает про задачу (A) в целом.

## Вопрос

Собрать 24 многочлена $U(x,y,z)$ (плюс 3 калибровочных) с $U(0)=0$, $\nabla U(0)=0$, у которых

1. $0$ — изолированная критическая точка над $\mathbb R$;
2. $0$ — не минимум (явный луч или кривая с $U<0$);
3. младшая форма $u_m\ge 0$ и обращается в нуль на сфере («жёсткое ядро»);

и **точно** определить, какие известные критерии неустойчивости к ним применимы. Не покрытые ни одним критерием
примеры — кандидаты для этапа 2.

## Результат в двух строках

- 24 примера + 3 калибровки (K1 — $x^4+y^4-z^6$, K2 — пример 13, K3 — пример теоремы B из `results/002`).
  Калибровка прошла: K1 покрыт квазиоднородным критерием (и ещё Burgos 1.4, симметрией); K2 покрыт **только**
  критерием примера 13 (N13, и эскизом N13\*), ни одним опубликованным критерием не покрыт.
- Из 24 новых: **19 не покрыты ни одним** из реализованных критериев; 3 покрыты нашими теоремами (C3, P2 — теоремой B;
  A6 — поворот примера 13, критерий N13); 2 (H1, H2: гессиан ≥ 0 с корангом 1 и 2) покрыты лишь условно (FGT08\*,
  гипотезы источника не сверены).

## Метод (что точно, что нет)

Код: `zoolib.py`, `criteria.py`, `analyze.py`, `sing.py` (обёртка над Singular); данные примеров — `catalog.py`.
Инструменты: Singular 4.4.1 (`pip install passagemath-singular`, бинарь
`~/venv/lib/python3.14/site-packages/sage_wheels/bin/Singular`), sympy 1.14, scipy 1.18 (только чтобы *найти*
рациональный сертификат — LP для весов, выпуклая оболочка для граней многогранника Ньютона; сам сертификат потом
проверяется точно). Случайных чисел нет, seed не нужен.

**Точные проверки (точная выкладка, методы указаны):**

- *Изолированность над ℝ.* Идеал $J=\langle\nabla U\rangle$; $K=J:p^\infty$ для положительно определённой квадрики $p$
  (насыщение, Singular). Любая вещественная критическая точка $q\ne0$ имеет $p(q)>0$, значит лежит в $V(K)$; если
  $K\not\subset\mathfrak m$, то $0\notin V(K)$ (замкнуто), и рядом с $0$ вещественных критических точек, кроме $0$,
  нет. Этот сертификат достаточный, он сработал для всех 27 примеров («ℝ ✓» в таблице). Дополнительно число Милнора
  $\mu$ — размерность локальной алгебры (`vdim` стандартного базиса в локальном порядке `ds`; $-1$ = бесконечно).
  $\mu=\infty$ у всех примеров с жёлобом-коникой, но не с кубикой T1 и не с плоским жёлобом F1 (комплексные изотропные прямые, как в `results/003`, теорема 2(в));
  при этом вещественная изолированность сертифицирована. Самопроверка (`selftest.py`): сертификат не срабатывает для
  $Q^2$ и $x^2y^2+z^4+y^4$ (неизолированы), срабатывает для $x^4+y^4+z^4$.
- *Не минимум.* Явный луч $w$ или кривая $\gamma(\tau)$; $U(\gamma(\tau))$ — многочлен по $\tau$, младший коэффициент
  точный и отрицательный. Для D1, D2 («жёлоб, который надо искать») кривая — отрезок ряда $x(\tau)$ на поверхности
  $Q-zm=0$ (рациональные коэффициенты; остаток поверхности порядка $\tau^{N+2}$ не влияет на младший член).
- *$u_m\ge0$.* Явное разложение $u_m=\sum c_jp_j^2$, $c_j>0$ (проверяется `expand`). Нулевое множество
  $\Sigma\subset S^2$ ($=\{p_j=0\}$) задано явно, и **полнота** проверена: $\mathrm{rad}\langle p_j\rangle$ равен
  пересечению идеалов заявленных компонент (Singular `radical`, `intersect`); значит, комплексные множества нулей
  совпадают, а тогда совпадают и вещественные.
- *Условия теоремы B* ((B1) гладкость и размерность $\Sigma$, (B2) Морс–Ботт, (B3) $0$ — регулярное значение
  $u_{m+1}|_\Sigma$): через насыщение идеалов $(f,\nabla f)$, $(f,\text{элементы гессиана }u_m)$,
  $(f,h,\det[\nabla h,\nabla f,q])$; единичный идеал означает отсутствие вещественных нулей. Если не единичный, ищется
  точный кратный нуль с целыми координатами (тогда условие нарушено доказательно), иначе «не решено».
- *Критерий типа примера 13 (N13\*, `results/003`, замечание 3, [Эскиз]).* $u_4=c\,Q^2$, $Q$ — круговой конус
  раствора $90^\circ$ (собственные значения $Q$ вида $(a,a,-a)$, точно), $W=U-u_4$, первая форма $W_{m'}$ имеет $0$
  регулярным значением на жёлобе и принимает там отрицательные значения.
- *Редукция к $n\le2$ (SYM).* Точный перебор **всех** плоскостей $\{n\cdot q=0\}$ и прямых $\mathbb Rd$, инвариантных
  для динамики ($n\cdot\nabla U=0$ на плоскости; $\nabla U(td)\parallel d$): карты для $n,d$, система уравнений на
  коэффициенты решается Singular + sympy. Это включает любые изометрические симметрии и «случайные» инвариантные
  плоскости (например, $y=0$, если $U$ не содержит $y$ в первой степени). Для рациональной плоскости ограничение $U$
  проверяется на отсутствие минимума: точный луч/ребро многоугольника Ньютона (тогда «✓»); если только плавающий скан
  видит отрицательные значения — «?»; иначе «·». Иррациональные нормали тоже «?» (у итоговых примеров таких нет).
  Для $n=2$ использована теорема Паламодова/Тальяферро/Козлова для аналитического потенциала
  [Литература: BP22 §1 по `problem/KNOWN_RESULTS.md`; первоисточники не сверены].
- *Квазиоднородность в линейных координатах (QH-linear):* точные веса $a>0$ (LP + точная проверка), $U$ принимает
  отрицательные значения (точно).
- *Паламодов 2020, теорема 6 (Pa20-T6):* компактные грани многогранника Ньютона; главная часть без вещественных
  критических точек вне 0 (сертификат: насыщение либо карты $z=\pm1$, $(z=0,y=\pm1)$, $(z=y=0,x=\pm1)$ после
  взвешенного масштабирования, решаются точно); отрицательные значения (точно); хвост по весам $\ge d+a_{\max}$
  («строгое» чтение) или $\ge d+a_{\min}$ («слабое»). Точная формулировка условия на хвост $O(|x||x|_w)$ в
  первоисточнике не сверена.

## Что в примерах трудного

Во всех примерах $u_m\ge0$ с нулями на сфере, поэтому не работают Ляпунов, KP82, Pa20-T3, Bu25-P1.2; нечётная вторая
форма делает невозможным Bu25-C1.4.

- **A1–A5, A7 — жёлоб-окружность (круговой конус раствора $90^\circ$), $u_4=Q^2$, кратные нули эффективного
  потенциала.** Ограничение $W_6$ (у A5 — $W_5$) на жёлоб по точной факторизации (`gutter_info`, рациональная
  параметризация конуса): A1 — $G\le0$ с двойным нулём; A2 — $G\ge0$ вблизи двойного нуля, $G<0$ вне него; A3 — тройные
  нули (смена знака с нулевым наклоном, $\sin^3\varphi$); A4 — $G\ge0$ всюду, двойной нуль, отрицательные значения $U$
  (по структуре, эвристика) только в тонком роге вокруг луча $(1,0,1)$, где $U=-t^7$ (точно); A5 — нечётный $W_5$ с касательным нулём (нарушено B3);
  A7 — $m=6$, $u_6=Q^2|q|^2$. Теорема 1 примера 13 требует простых нулей; для кратных нужно следующее раздутие в
  кончике рога.
- **C1, C2 — другой конус-жёлоб:** эллиптический ($x^2+2y^2-z^2$) и круговой с раствором $\ne90^\circ$
  ($x^2+y^2-2z^2$), эффективный потенциал с простыми нулями. По структуре это пример 13, но доказательство в
  `results/003` написано в координатах $(s,d)$ конкретного конуса. C3 — эллиптический конус с нечётным $W_5$: покрыт
  теоремой B (контраст).
- **D1 — «жёлоб, который надо искать»:** $(Q-zm)^2-z^8$, $m=x(x+2y)+3xz$. $U_5=-2Qzm\equiv0$ и $U_6=z^2m^2\ge0$ на
  конусе; настоящий жёлоб — деформированная поверхность $Q=zm$. **D2** — пример 13 на деформированном конусе
  ($Q\to Q-zm$): жёлоб — искривлённая поверхность, не конус. Замечание: если $m$ зависит только от $(x,y)$, главные оси
  $m$ дают инвариантные плоскости (симметрию), и пример сводится к $n=2$; поэтому в $m$ добавлено $3xz$ (точный поиск
  инвариантных плоскостей подтвердил: их нет).
- **F1 — плоский жёлоб** $z=0$ ($u_4=z^2|q|^2$): $u_5=z(x^4+2xy^3)$ равна 0 на нём; эффективный потенциал
  $W_6-f_4^2/(4\rho^2)$ получается дополнением до квадрата (не многочленное ограничение).
- **M1 — кратность 4** ($u_4=z^4$), отрицательность вдоль параболы: $(z-x^2)^4+x^5+y^5+\dots$ квазиоднороден лишь
  после нелинейной замены $z\to z-x^2$ (в линейных координатах хвост $z^3x^2$ имеет вес 23 < $d+a_{\min}=24$).
  **M2, P1** — главная квазиоднородная часть без критических точек, но хвост попадает в «щель» условия теоремы 6
  (M2: $z^4+z(x^4+x^3y+y^4)$, хвост веса 18 < 19; P1: $x^4+y^4-z^6$ + хвост веса 13 < 14).
- **P3, P4, Z1, S1, T1 — нарушения условий теоремы B:** P3 — $u_5$ обращается в 0 в двух из четырёх направлений нулей
  (B3); P4 — три оси, $u_5(e_z)=0$ (B3); Z1 — $\Sigma$ = экватор $\cup$ полюса (разные размерности, B1); S1 — особый
  жёлоб (две пересекающиеся окружности, B1); T1 — жёлоб — гладкая кубика $y^2z=x^3+xz^2$ ($m=6$, не коника).
- **H1, H2 — гессиан ≥ 0, $m=2$:** «кривая долина» (витая кубика) и «каспидальная долина». Покрыты условно (FGT08\*);
  Koz86 буквально неприменим ($u_3|_{\ker u_2}\equiv0$).

Побочные наблюдения [Эксперимент]: (i) пример теоремы B из `results/002` ($Q^2+xz^4$, K3) симметричен
относительно $y\to-y$, так что покрыт и редукцией к $n=2$; пример, покрытый именно теоремой B, — C3, P2.
(ii) При конструировании первые варианты A3, M1, M2, P4, Z1, T1 и D1 оказывались тривиально сводимыми к $n=2$ или $n=1$
(инвариантная координатная плоскость/ось без всякой симметрии, потому что $U$ не содержит нужных линейных членов;
для D1 — главные оси $m$). В итоговом каталоге эти случаи устранены добавлением линейных членов; точный поиск
инвариантных подпространств это подтверждает.

## Что показано и чего НЕ доказано

Показано (точные выкладки, методы выше): изолированность над ℝ; $U<0$ вдоль явной кривой; $u_m\ge0$ с нулевым
множеством $\Sigma$; вердикты условий критериев (при указанном прочтении условий); структура эффективного потенциала
на конусных жёлобах (кратности нулей); у не покрытых примеров все найденные линейные инвариантные плоскости и прямые дают на ограничении локальный минимум
(редукция к $n\le2$ ничего не даёт; в пределах поиска линейных инвариантных подпространств).

**Не доказано и не утверждается:**

1. Ни одного утверждения о неустойчивости. Для 19 не покрытых примеров задача (A) *открыта в нашем арсенале*;
   «не покрыт» — не «устойчив» и не «контрпример». По гипотезе все они неустойчивы.
2. «Не покрыт» относится только к реализованному списку критериев при нашем прочтении условий (Pa20, Bu25, Koz86,
   FGT08 первоисточниками не сверены; условие на хвост теоремы 6 — по записи в `KNOWN_RESULTS.md`). Другой метод или
   более слабое прочтение условия может покрыть пример.
3. Теорема B (`results/002`) ждёт повторной проверки; N13\* — [Эскиз]. «Покрыт теоремой B» имеет вес этих статусов.
4. SYM ищет только инвариантные плоскости и прямые через 0; искривлённые инвариантные поверхности не искались.
5. Pa20-T6 перебирает только компактные грани (положительные нормали), а не произвольные веса.
6. Сертификат вещественной изолированности достаточный (сработал во всех 27 случаях). Для $\mu<\infty$ точка изолирована
   и над ℂ.
7. Динамика не считалась: траектории, энергии, «рога» не исследовались. Это естественный этап 2 для кандидатов
   (но время ухода оценивается как $C/|h|\sim r^{-m}$, поэтому прямое интегрирование на малых масштабах трудно).
8. Код прежнего «решета» (`experiments/vlad-claude-tg/sieve/`) не использовался: проверки переписаны на точные
   методы; идеи (семейства, список критериев) взяты оттуда.
