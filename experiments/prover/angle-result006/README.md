# angle-result006: символьные проверки к `results/006-angle-lemma.md`

prover (агент), 21.10.2026. Всё здесь — [Эксперимент]: свидетельство, не доказательство.

- **Вопрос.** Сверить выкладки в замечаниях результата 006: тождество Эйлера (однородный $U$),
  $\langle x,\nabla U\rangle-mU=\sum_k(k-m)u_k$ (невырожденная младшая форма), квазиоднородный пример
  $(y-x^2)(y-2x^2)$, главный член $g$ в одной точке рога $(y^2-x^3)^2-x^{10}$, знаки $f'$ в
  отрицательном слое радиальной функции $e^{-1/r^2}\sin(1/r)$.
- **Метод.** sympy (точная арифметика, ряды по $u=x^{1/2}$); для п. 5 — mpmath, 30 знаков, сетка из
  399 точек в слое $k=3$.
- **Запуск.** `~/venv/bin/python check_remarks.py > check_remarks.out`.
- **Что показано.** Тождества пп. 1–3 выполнены точно; в точке $p=(x,x^{3/2}(1-x^2/4))$ рога
  $U(p)=-\tfrac34x^{10}+\dots<0$ и $g(p)=\tfrac12x^{1/2}-\tfrac{13}{16}x+O(x^{3/2})$; в слое $f<0$, и
  $f'$ принимает оба знака.
- **Чего не показано.** Оптимальный показатель $d$ для $(y^2-x^3)^2-x^{10}$ здесь не вычисляется: точка
  $p$ даёт только нижнюю оценку $\sup g$ на сфере. Численная оценка самого $\sup$ — в
  `experiments/prover/angle-nD/angle_exponent_frac.py`.
