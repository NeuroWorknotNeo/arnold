# Исправленная конструкция поля Паламодова на плоскости: численная проверка

Это [Эксперимент]. Он иллюстрирует доказательство, но не заменяет его. Заметка:
`notes/prover/2026-10-21-palamodov-plane-corrected.md`, §6–§8. Автор — prover (агент), 21.10.2026.

## Вопрос

Выполняются ли для исправленной огибающей $\Delta$ условия (I), (III), (2), (IV), (3)? Огибающая
строится как max/min «палаток» по замкнутой дуге рога, концевые куски входят автоматически. Нужны ли
концевые куски, то есть верно ли, что без них конструкция [P77] ломается?

## Файлы

- `jacobian_sympy.py`, вывод в `jacobian_sympy_out.txt`. Символьная сверка (sympy):
  - матрица $Dv$ поля $v=R_\Delta x$ в репере $(e_r,e_\alpha)$;
  - формула наименьшего собственного числа $\mu$;
  - тождество $\langle v,\nabla U\rangle\propto-\cos(\varphi-\Delta)$;
  - нижняя оценка $\mu$ (на $2\cdot10^5$ случайных точках).
- `construct.py`, вывод в `construct_out.txt`, время работы около 5 мин. Конструкция на окружностях
  $r=10^{-1},10^{-2},10^{-3}$ для следующих потенциалов:
  - $u_1=-x_2(x_1-x_2^2)$, обе компоненты;
  - $u_2=x_1^5-(x_2-x_1^2)^2$;
  - $u_3=x_1^3-x_2^2$;
  - $u_4=-(x_2-x_1^2)^2-x_1^6$ — вся окружность, периодический случай;
  - $u_5=(x_2-x_1^2)(x_2-x_1^3)$;
  - $u_6=(x_2-x_1^2)^2-x_1^6$, оба рога.
- `p77_no_endpoints.py`, вывод в `p77_no_endpoints_out.txt`. Проверяет, есть ли на отрезке у конца
  дуги, где $\tau\ne0$, точки касания (11) из [P77]. Если их нет, то $\Delta$ из [P77] равна там
  $\tau$ и нарушает III.

## Метод и параметры

- **Константы:** $\gamma_1=0.5$, $\eta_1=2$, $\varepsilon_1=r+\max_{\rm arc}(|\varphi|-\pi/2)^+$,
  $\lambda_H=-2\varepsilon_1/\gamma_1$.
- **Дуга:** смена знака $U$ ищется на объединении геометрической (множитель 1.0005) и равномерной
  (шаг $2\pi/8\cdot10^6$) сеток расстояний от тестовой точки, затем `brentq`.
- **Сетка по $\alpha$:**
  - $4\cdot10^5$ равномерных точек плюс сгущение к концам дуги до $10^{-13}$ её длины;
  - измельчение до $|\Delta\varphi|\le2\cdot10^{-3}$;
  - там, где $|\varphi|>\pi/2-3\varepsilon_1$, — до $|\Delta\varphi|\le5\cdot10^{-3}\varepsilon_1$.
- **Огибающая:** max/min по сетке считается точно, через кумулятивные максимумы.
- **$r\Delta'_r$:** центральная разность с относительным шагом $h=\min(0.02,0.2r)$. $\Delta$ на
  радиусах $r(1\pm h)$ вычисляется в тех же $\alpha$ как max по (сетка $\cup\{\alpha\}$), без
  интерполяции.
- **Без случайности:** seed не нужен.

Воспроизведение:

```
cd experiments/prover/palamodov-plane
~/venv/bin/python -I jacobian_sympy.py > jacobian_sympy_out.txt
~/venv/bin/python -I construct.py > construct_out.txt
~/venv/bin/python -I p77_no_endpoints.py > p77_no_endpoints_out.txt
```

## Что показано

- При $r=10^{-2}$ и $10^{-3}$ во всех примерах:
  - (I) выполнено с точностью до округления;
  - носители $\Delta^\pm$ не пересекаются;
  - наклоны лежат в $[\lambda_H,\lambda_B]$;
  - (2) выполнено;
  - $\max|r\Delta'_r|\to0$;
  - $\min\mu\ge0.76$ при $r=10^{-2}$ и $\ge0.93$ при $r=10^{-3}$.
- При $r=10^{-1}$ $\mu$ ещё мало ($-0.004$ для $u_2$), что согласуется с требованием малого $r$.
- Концевые куски необходимы. В $u_1$ ($Q_1$), $u_2$, $u_3$, $u_5$, $u_6$ у конца дуги $\tau\ne0$, и
  наклон $\tau'$ там всюду вне $[\lambda_H,\lambda_B]$ (от $-2$ до $-3.3\cdot10^5$), а точек касания
  нет. Следовательно, $\Delta$ из [P77] нарушает III.

## Чего эксперимент не доказывает

- Сетка конечна, $r\Delta'_r$ — разностная оценка.
- $\gamma_1$ и $\eta_1$ взяты с запасом, а не из леммы 6.
- Проверены несколько радиусов и семь рогов шести потенциалов.
- На ячейках короче $10^{-9}$ длины дуги разностные отношения дают шум округления и исключены из
  отчёта о наклонах.
- На ячейке, где $\Delta^+$ сменяется на $\Delta^-$, дискретное отношение может доходить до
  $2\lambda_H$: нуль между узлами не разрешён. В выводе такого не встретилось.
