# Пример 13: проверка выкладок results/003

prover, 21.10.2026. Сопровождает [`results/003-example13.md`](../../../results/003-example13.md).
Статус всего ниже — **[Эксперимент]**: символьная проверка, а не доказательство.

## Вопрос

Верны ли тождества и константы, на которые опирается текст results/003 для
$U=(x^2+y^2-z^2)^2+z^5x+z^4xy+\tfrac12z^6$, в первую очередь добавленные при исправлении
(доказательство изолированности над $\mathbb R$, оценка $|G''|\le3$, неизолированность над $\mathbb C$)?

## Метод

`check_result003.py` (SymPy, точная арифметика; в п. 10 — сетка NumPy):

1. $Q^2=4s^2d^2$; $U_6$ однороден степени 6 по $(s,d)$; список $a_0,\dots,a_6$.
2. $a_0=G/8$; формула для $a_1$ и $a_1'$.
3. $\tfrac16E(U)-U=\tfrac16\sum_j ja_js^{6-j}d^j$.
4. $\widetilde U(0,\varphi,\eta)=4\eta^2+G/8$; $\partial_dU=s^4\widetilde U_\eta$; формула $\Phi(0,\cdot)$;
   $V(U)-\alpha U=s^6\Phi$.
5. $G'=-(2\sin\varphi-1)(1+\sin\varphi)$, $G''=-(\cos\varphi+2\sin2\varphi)$, значения $G$ в критических
   точках, нули $G$.
6. Константы леммы 6.
7. Тождества доказательства теоремы 2: $yU_x-xU_y=z^4(y^2+yz-x^2)$, разложение $U_z$, подстановка в
   $U_y$, выражения $p_1,p_2$ через $\tau=\rho/z$.
8. Базис Грёбнера $\{p_1,p_2,c^2+\sigma^2-1\}$ равен $\{1\}$ (нет общих нулей на окружности).
9. Прямые $z=0$, $x=\pm iy$ состоят из комплексных критических точек.
10. Численно: $\min(|p_1|+|p_2|)\approx1.098$ (сетка $2\cdot10^6$ точек), $A=\max_{|q|=1}|U_6|\approx0.631$,
    $\max|a_1'|=0.75$, $\max|G''|\approx2.736$.
11. $U\bigl(a(-\tfrac{\sqrt3}2,\tfrac12,1)\bigr)=a^6(\tfrac12-\tfrac{3\sqrt3}4)$.

## Как воспроизвести

```bash
~/venv/bin/python check_result003.py
```

Время работы — около минуты.

## Результат

Все тождества п. 1–9 и 11 выполняются точно; численные значения п. 10 приведены выше. Отдельно
(одноразовый расчёт в сессии, по базису Грёбнера из
[`experiments/reviewer/example13/isolated_groebner.py`](../../reviewer/example13/isolated_groebner.py)):
вещественные критические точки $U$, кроме $0$, — только $\pm(5.2685,-8.0245,4.5654)$, $|q|\approx10.63$.

## Что это не доказывает

Проверка тождеств не заменяет доказательств лемм; сетка в п. 10 даёт лишь численные значения
констант, а в тексте результата используются только их доказанные оценки ($c_0>0$ по компактности,
$A\le2$, $|a_1'|\le\tfrac34$, $|G''|\le3$).
