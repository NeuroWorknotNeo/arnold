$\mu'=12\delta/C_M^2$ (минимум $\approx\mu'$), порог $\mu'_{\rm crit}\approx8\delta$ для поля предложения O2, рост нарушения как $s^{1-c}$ у нетреугольного поля.
**Чего не показано:** ничего из этого не доказательство; сетки конечны, минимум по $(\theta,\kappa)$ найден лишь приближённо (по сетке
с уточнением), порог зависит от конкретного поля $X_0$ (срезки $\chi$).
