| Скрипт | Что проверяет |
|---|---|
| `check_dv_formula.py` | квадратичная форма $Q$ предложения 6 против прямого $Dv$ при $n=3$ (рациональные данные); при $n=2$ — совпадение с матрицей [P77, с. 52] (обзор, `prop:rotated`) |
| `check_dv_matrix.py` | явная матрица $Dv$ предложения 6 в репере $(e_r,e_\theta,e_\varphi)$ |
| `check_tau_bound.py` | $\lvert\operatorname{sinc}'t\rvert\le t/3$ на $(0,1]$; оценка $\operatorname{sym}Dv$ предложения 6 на $2\cdot10^5$ случайных наборах ($n=2,3,4$) |
| `angle_exponents.py` | $M(r)=\sup g$ на $\{U<0\}\cap S_r$ для трёх плоских примеров (теорема 1, показатель $d$) |
| `angle_exponent_frac.py` | дробный показатель $d=1/2$ для $(y^2-x^3)^2-x^{10}$ |
| `ex_tube.py` | пример 10 ($U_3$, $U_4$): тождество для $R$, сетка, ряды на «берегах» перемычки, пары, сечения $P_s$ |
| `ex_pinch.py`, `ex_pinch_planes.py`, `ex_pinch_U2.py` | то же для полосы $U_1=y^2-(x^2+z^2)((z-x^2)^2+x^6)$ и её сдвига $U_2$ |
