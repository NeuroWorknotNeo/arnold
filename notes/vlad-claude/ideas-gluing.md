# Идеи: как склеивать поля Паламодова (vlad-claude, 27.09.2026)

Везде K евклидова, U(0)=0, X = {U<0} ∩ W.

## 0. Критерий (L') [Доказано, см. palamodov2020.md]
Если на X есть ограниченное C¹-поле A с sym DA ⪰ −δ(x)I и A(U) ≤ P U, P ≥ 2δ + ε, ε>0,
то 0 тотально неустойчива (достаточно, чтобы <x',A> было ограничено на подуровнях).

## 1. Двойственность [Эскиз]
Условие «Ḟ_A(x,v) = vᵀDA v − A·∇U ≥ c > 0 на {U ≤ E}» линейно по A. По теореме
отделимости (условия и регулярность надо выписать) отсутствие такого A для данного W
равносильно существованию ненулевой положительной меры μ на {(x,v): x ∈ X̄, |v|²/2 ≤ E−U}
с ∫Ḟ_A dμ ≤ 0 для всех A. В терминах тензора напряжений T_ij(x) = ∫ v_i v_j dμ(·|x) ρ(x):
div T = −ρ∇U (в смысле распределений, с граничными членами на ∂W), T ⪰ 0.
Инвариантные меры потока (периодические орбиты и т.п.) — частный случай. Значит метод
полей, линейных по скорости, «ровно настолько силён», насколько нет таких
«статических равновесий напряжений» внутри {U<0}. Вопрос: бывают ли они у аналитических U?
(Если бывают — метод Паламодова–Burgos принципиально не проходит.)

## 2. Склейка в логарифмическом масштабе [Эскиз]
Ошибка склейки A = Σ f_p A_p: член Σ (A_p − A_q) ⊗ ∇f_p. При разбиении «по секторам
раздутия» |∇f| ~ 1/r, |A_p − A_q| ~ r ⇒ O(1).
Для диагональных взвешенных полей Эйлера A_w = Σ w_j x_j ∂_j (такими становятся поля
w∂w торических карт) переходы между режимами |x_j| ~ |x_1|^{τ_j} можно делать функциями
от τ_j = log|x_j| / log|x_1|, которые меняются медленно:
  ошибка (j,k) = (w_j − w'_j) x_j ∂_k f ≈ (w_j − w'_j) f_{τ_k} x_j / (x_k L), L = log(1/|x_1|).
Если нормировать веса так, что у «доминирующей» координаты вес одинаков (w_1 = w'_1 = 1),
то при n=2 ошибка O(1/L) → 0: склейка проходит.
При n ≥ 3 нужна комбинаторика: ошибка мала, только если f не зависит от τ_k там, где
найдётся j с w_j ≠ w'_j и |x_j| ≫ |x_k| (полиномиально). Т.е. при переходе через стенку
веера, где меняется «вес» координаты x_k, веса всех более крупных координат должны быть
согласованы. Надо проверить, можно ли так выбрать веса в конусах двойственного веера
(свобода: в каждом конусе годится любой вес из относительной внутренности? — проверить).

План проверки: (а) n=2, U Newton-невырожден — заново получить тотальную неустойчивость
(известно: Паламодов 1977, не сверено) этим способом; (б) n=3, Newton-невырожденный U —
если проходит, это новый класс для тотальной неустойчивости (проверить литературу:
Козлов–Фурта, многогранник Ньютона, асимптотические решения — это для Ляпунова).
Трудный случай — нулевые множества главных частей внутри тора и «искривлённые»
направления (y − x² и т.п.), где торических полей мало: нужна коррекция типа R Паламодова.
