# Конспект: В. П. Паламодов, «Об обращении теоремы Лагранжа–Дирихле и неустойчивости консервативных систем», УМН 75:3 (2020), 107–122 (рус.), RMS 75:3, 495–508

Прочитан полный русский текст (mathnet.ru, свободный доступ), 27.09.2026, vlad-claude.
Нумерация — по статье.

- **Опр. 1 (тотальная неустойчивость).** Есть окрестность Ω точки x0 такая, что любое
  движение, стартующее в T(Ω) с энергией E < U(x0), уходит на ∂Ω за конечное время.
- **Гипотеза 1.** Всякая точка равновесия аналитического потенциала тотально неустойчива.
  (В самой статье 2020 года это **гипотеза**, не теорема. Анонс «теоремы» был в Palamodov,
  Transl. AMS 168 (1995) — по [B21].)
- Утверждается: тотальная неустойчивость для любых аналитических U на R² установлена в
  [22] = Паламодов, Функц. анализ 11:4 (1977). [Литература, не сверено с [22]]
- **Теорема 2 [22] (критерий поля).** Пусть на X = {U < U(x0)} ∪ {x0} есть C¹ поле A
  (производные непрерывны вплоть до x0) такое, что
  (I) форма Q(A, x0, ξ) = B(x0; ξ, ξ·∇A(x0)) неотрицательно определена;
  (II) P = A(U)/U удовлетворяет inf_X P > 0.
  Тогда x0 тотально неустойчива.
  Доказательство: F = B(x; x', A) = <x', A> (для евклидовой K), Ḟ = −A(U) + <x', ∇_{x'}A> + A(K)
  (последний член — от зависимости метрики от x; для евклидовой = 0);
  <v,∇_vA>(x) ≥ Q(x0) − b(x)K, b→0; K = E − U ≤ −U, откуда Ḟ ≥ (b+v−P)U ≥ −εE.
  **[Проверено: vlad-claude, для евклидовой K]** Замечание: из доказательства видно, что
  достаточно более слабого (и масштабно-инвариантного) условия
  (L') sym DA(x) ⪰ −δ(x) I и P(x) ≥ 2δ(x) + ε на X ∩ W, ε > 0, A ограничено (или
  <x',A> ограничено на подуровне). Выкладка: Ḟ ≥ −δ|v|² − PU, |v|² = 2(E − U) ≤ −2U,
  значит Ḟ ≥ (2δ − P)U ≥ −ε U ≥ −εE. [Доказано]
  Функционал A ↦ P_A − 2δ_A вогнут (P линейно, δ_A = max(0, −λ_min sym DA) выпукло),
  так что «хорошие» поля образуют выпуклый конус в каждой точке.
- **Сложение:** поля для U(y), V(z) с P=1 складываются в поле для U(y)+V(z).
- **Пример 3.** U2 = −((y−x²)⁵(y−2x²)⁵ + (z−x³)²)² — не квазиоднороден, поле
  A = x/20 ∂x + y/10 ∂y + (z/2 − 7x³/10) ∂z, A(u)=u, Q ≥ 0 при |x| < √(2/21).
- **Теорема 3.** U = u_m + u_{m+1} + …, ∇u_m ≠ 0 при x ≠ 0 ⇒ тотальная неустойчивость.
  Поле A = E/m − U₊ R/(1+R(v)), R = ∇u_m/|∇u_m|², U₊ = E(U)/m − U. DA∞ → 0 в нуле.
- **Теорема 5.** Сводит к ограничению на ядро квадратичной части (преобразования из G_K).
- **Теорема 6.** Квазиоднородная главная часть u (веса w, порядок 1) без критических точек
  вне 0 и v = O(|x|·|x|_w) ⇒ тотальная неустойчивость.
- Во введении: для аналитических систем общего вида (не натуральных) в чётномерном фазовом
  пространстве асимптотического движения может не быть (Козлов–Трещёв 2018, MMJ 18:4).

## Связь с Burgos (arXiv:2108.05829v4)
Burgos пытается построить поле A из теоремы 2 для любого U через монализацию Хиронаки.
По доказательству ему достаточно (L') — но и это не выполнено у его склейки: член
Σ ∇f_p ⊗ V_p = Σ (V_p − V_q) ⊗ ∇f_p имеет порядок |V_p − V_q| / r ~ 1, т.е. сравним с P.
Для одной карты (мой контрпример U = x(y−3x)): λ_min(sym DV_p) ≈ −0.081, P = 3, так что
(L') в этой карте **выполнено**; лемма 2.2 формально ложна, но локально дефект мал. Главная
проблема — склейка.
