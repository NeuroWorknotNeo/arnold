# Гипотеза П при n = 2 (эскиз): покрытие режимами по Ньютону–Пюизё

vlad-claude, 27.09.2026, ход 6. Статус: **[Эскиз]**. Результат при n = 2 известен
(Паламодов 1977 — тотальная неустойчивость; Козлов/Taliaferro — по Ляпунову). Цель —
проверить инструменты `toolkit.md`, `lemmaR-proof.md` на полном классе.

U аналитична около 0 ∈ ℝ², U(0) = 0, 0 — изолированная критическая точка. Отсюда
U **приведена**: кратный множитель f² даёт ∇U = 0 на {f = 0}.

1. **Радиальный режим.** Полярная карта, блок θ (w = 1), F = u_m(cos θ, sin θ), d = m,
   e = 1. На K = {dist(θ, Σ) ≥ δ}, Σ = нули u_m на S¹, выполнено |F| ≥ c_0: коррекция не
   нужна, A = r∂_r.
2. **Трубка около ω_0 ∈ Σ.** Координаты x вдоль ω_0 (x > 0), y — по нормали.
   Многоугольник Ньютона U в (x, y), грани с весами 1 = w_0 < w_1 < … (y ~ x^w).
   - Грань σ, вес w: карта (x, y) = (r, r^wŷ), F_σ(ŷ) — многочлен грани, e > 0 — зазор до
     следующих точек решётки (кратный 1/N). На K = {δ ≤ |ŷ| ≤ 1/δ} без окрестностей
     кратных вещественных корней (Reg) выполнено: у простых корней F' ≠ 0 (J ∋ y — самый
     тонкий блок). Лемма R.
   - Вершина между гранями w и w': одночлен x^ay^b доминирует, |F| ≥ c_0, коррекция не
     нужна. Веса y интерполируются от w к w' по u = log|y|/log x (лемма G(b): меняется
     только вес самой тонкой координаты y).
   - Нижний край: если y | U (y = 0 — ветвь), то около y = 0 U = y·Ũ, Ũ(x, 0) ~ cx^a, и
     поле x∂_x + W y∂_y при большом W даёт P ≈ W + a > 0 без коррекции.
   - Кратный вещественный корень ŷ_0 грани веса w: подрежим в координатах
     y' = y − ŷ_0x^w. Поле родителя x∂_x + wy∂_y в новых координатах равно
     x∂_x + wy'∂_{y'}: кривая y = ŷ_0x^w инвариантна. Область |y'| ≤ δx^w — вершина нового
     многоугольника (доминирует (y')^μ), дальше новые грани с весами w' > w, и так далее.
     Карта (x, ŷ_0x^w + x^{w'}ŷ') ортогональна в смысле (O) асимптотически, потому что
     наклон x^{w−1} → 0.
   - Конечность: ветви {U = 0} (и комплексные) — различные ряды Пюизё, поэтому алгоритм
     Ньютона–Пюизё разделяет все вещественные кратные корни за конечное число шагов
     (кратность падает или порядок касания растёт, но он ограничен порядком расхождения
     рядов).
3. **Склейки.** Радиальный режим с трубкой — по θ при одинаковом поле (x∂_x + y∂_y =
   r∂_r при w = 1; G(a), коррекций нет). Внутри трубки — G(b) по y или по y'.

Пробелы: аккуратная лемма G(b) для семейства режимов в переходной зоне (там нужна
проверка A(U) ≤ pU при промежуточных весах; в вершинной зоне она очевидна — одночлен);
согласование компактов K разных режимов (покрытие без щелей); случай x < 0 — это
другой луч −ω_0.
