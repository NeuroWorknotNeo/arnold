# Лемма R (поле в одном режиме): формулировка и доказательство

vlad-claude, 27.09.2026, ход 6. Статус: **[Доказано]** автором, ждёт проверки.
Обобщает §4–§5 `theoremB-proof.md` (там — частный случай, см. §5 ниже).

## 1. Карта режима

- **Блоки и веса.** ŷ = (ŷ_0, ŷ_1, …, ŷ_k): ŷ_0 пробегает открытое множество в ℝ^s
  (угловые координаты), ŷ_i ∈ ℝ^{c_i}. Веса: w_0 = 1 < w_1 < … < w_k, рациональные.
  Пусть N — общий знаменатель, a_i = N(w_i − 1) ∈ ℤ_{≥1}. Масштабы: s_i := r^{w_i},
  s_0 = r; «радиальный» блок — это сама координата r с масштабом 1·r (вес 1).
- **Отображение.** Φ(r, ŷ) = r Γ(ŷ, ε), ε = r^{1/N}, где
  Γ(ŷ, ε) = G(ŷ_0, ε^{a_1}ŷ_1, …, ε^{a_k}ŷ_k, ε), G ∈ C³ в окрестности K̃_0 × {0} × [0, ε_0]
  (K̃_0 — компакт в ℝ^s).
- **(O) Ортогональность.** Пусть ω(ŷ_0) := G(ŷ_0, 0, 0), T_0 := образ D_{ŷ_0}G(ŷ_0,0,0) и
  N_i := образ D_{μ_i}G(ŷ_0,0,0). Требуется: |ω| = 1, ранги полные, и
  ℝⁿ = ℝω ⊕ T_0 ⊕ N_1 ⊕ … ⊕ N_k — **попарно ортогональная** сумма.
- **(Φ)** Φ — C²-диффеоморфизм (0, ρ) × K̃ на открытое множество, где K̃ — компакт в
  ŷ-пространстве с внутренностью K̃°. Этого можно добиться, уменьшив ρ, когда K̃
  лежит в достаточно малой окрестности {ŷ_{≥1} = 0}. В общем случае это требование к карте.
- **Разложение.** U∘Φ = r^d (F(ŷ) + r^e H(ŷ, ε)), d > 0, e ∈ (1/N)ℤ_{>0},
  F ∈ C², H ∈ C² на K̃ × [0, ε_0].

## 2. Утверждение

Пусть J — множество блоков (включая, возможно, радиальный и угловой) с весом w_j,
удовлетворяющим **w_k − w_j < e**. Пусть K ⊂ K̃° — компакт и c_0 > 0 таковы, что
$$\text{(Reg)}\qquad \forall\hat y\in K:\ |F(\hat y)|\le c_0\ \Rightarrow\ D_J(\hat y)\ge c_0^2,$$
где D_J = Σ_{j∈J, j≥0} |∂_{ŷ_j}F|² + [r∈J]·(dF)². Производные по ŷ_0 берутся по
евклидовой метрике карты.

Тогда найдутся ρ' > 0 и C¹-поле A на Φ((0,ρ') × K°) с
1. A(U) ≤ (d/2)·U в точках, где U < 0;
2. sym DA ⪰ ½ I;
3. |A(x)| ≤ C|x|.

(Вместе с леммой 1 из `theoremB-proof.md`: если {U<0} ∩ B_{ρ''} ⊂ Φ((0,ρ') × K°'), где K°'
отделено от края K, то 0 тотально неустойчива.)

## 3. Построение

V := r∂_r (в координатах (r, ŷ)). Пусть χ ∈ C^∞(ℝ), χ = 1 на [−c_0/2, c_0/2], χ = 0 вне
(−c_0, c_0). Положим
$$U_+ = V(U) - dU,\qquad
\hat W = -\chi(F)\,U_+\,\frac{\sum_{j\in J,j\ge0}(\partial_{\hat y_j}U)\,\partial_{\hat y_j}
+[r\in J]\,(r\partial_rU)\,r\partial_r}{\sum_{j\in J,j\ge0}|\partial_{\hat y_j}U|^2+[r\in J](r\partial_rU)^2},
\qquad A=V+W.$$

**Шаг 1 (формулы).** Из разложения:
∂_{ŷ_j}U = r^d(∂_jF + r^e∂_jH), r∂_rU = r^d(dF + r^e((d+e)H + εH_ε/N)),
U₊ = r^{d+e} P(ŷ, ε), где P = eH + εH_ε/N ∈ C¹. Знаменатель равен
r^{2d}(D_J + O(r^e)) ≥ r^{2d}c_0²/2 на носителе χ(F) при малом r. Поэтому
$$\hat W = r^e\Bigl(c(\hat y,\varepsilon)\,r\partial_r+\sum_{j\in J}Y_j(\hat y,\varepsilon)\,\partial_{\hat y_j}\Bigr),$$
где c (равное нулю, если r ∉ J) и Y_j — C¹-функции от (ŷ, ε) на K × [0, ε_0]; при этом
r^e = ε^{Ne}.

**Шаг 2 (пункт 1).** A(U) = dU + U₊ − χU₊ = dU + (1−χ(F))U₊. Если χ(F) < 1, то
|F| ≥ c_0/2. Если к тому же U < 0, то при малом r F ≤ −c_0/4, откуда |U| ≥ c_0r^d/8, а
|U₊| ≤ Cr^{d+e} ≤ (d/2)|U|. Итак, A(U) ≤ dU + (d/2)|U| = (d/2)U. Если χ = 1, то
A(U) = dU. ∎

## 4. Оценки производных

**4.1. Якобиан.** ∂_rΦ = Γ + εΓ_ε/N; ∂_{ŷ_0}Φ = rΓ_{ŷ_0};
∂_{ŷ_i}Φ = rε^{a_i}D_{μ_i}G(…) = s_i(D_{μ_i}G(ŷ_0,0,0) + O(ε)). Значит,
DΦ = Q·S, S = diag(1, r I_s, s_1 I_{c_1}, …, s_k I_{c_k}), Q = Q_0(ŷ_0) + O(ε), где столбцы
Q_0 — это ω, D_0G, D_{μ_i}G при ε = 0. По (O) Q_0 обратима, так что Q, Q^{-1}
равномерно ограничены на K × [0, ε_0]. Строки DΦ^{-1} = S^{-1}Q^{-1}, отвечающие r и
блоку i, имеют порядок O(1) и O(1/s_i). Вторые производные (G ∈ C³):
∂_{ŷ_i}∂_{ŷ_j}Φ = O(s_is_j/r) для любых блоков i, j ≥ 0 (включая угловой, s_0 = r);
∂_r∂_{ŷ_j}Φ = O(s_j/r).

Для поля Â в координатах (r, ŷ) и A^x∘Φ = DΦ·Â имеем
$$DA^x=\bigl(D^2\Phi[\hat A,\cdot]+D\Phi\,D\hat A\bigr)D\Phi^{-1}.\tag{*}$$

**4.2. Поле V.** V^x = r∂_rΦ. По 4.1: r∂_r(∂_{ŷ_j}Φ) = w_j ∂_{ŷ_j}Φ + s_j·O(ε).
Действительно, ∂_{ŷ_j}Φ = s_j D_jG(ŷ_0, (ε^{a_i}ŷ_i), ε), r∂_r s_j = w_js_j, а r∂_r
аргументов G равен O(ε). При j = 0 то же верно с w_0 = 1. Далее,
∂_r(r∂_rΦ) = ∂_rΦ + O(ε). Итак, D_{(r,ŷ)}V^x = DΦ·Λ + E, где Λ = diag(1, I_s, w_1I, …, w_kI),
а столбцы E имеют порядки O(ε) (радиальный) и s_j·O(ε) (блок j). Отсюда
$$DV^x=Q\Lambda Q^{-1}+E\,S^{-1}Q^{-1}=Q_0\Lambda Q_0^{-1}+O(\varepsilon)
=P_\omega+P_{T_0}+\sum_iw_iP_{N_i}+O(r^{1/N}),$$
где P — ортопроекторы. Последнее равенство верно потому, что Λ скалярна на каждом блоке,
а образы блоков Q_0 попарно ортогональны. Значит, sym DV^x ⪰ (1 − Cr^{1/N}) I.

**4.3. Радиальная часть W:** r^e c·V. D(r^ec V^x) = r^e c DV^x + V^x ⊗ ∇_x(r^ec).
Первое слагаемое O(r^e). Далее, ∇_x(r^ec) = D_{(r,ŷ)}(r^ec)·DΦ^{-1}: вклад ∂_r даёт
O(r^{e−1}), вклад ∂_{ŷ_i} даёт O(r^e)·O(1/s_i) ≤ O(r^{e−w_k}). Так как |V^x| = O(r),
получаем O(r^e + r^{1+e−w_k}). Здесь r ∈ J означает w_k − 1 < e, так что это o(1). (Если
r ∉ J, то c = 0.)

**4.4. Остальная часть W:** Ŵ_Y = r^eΣ_{j∈J}Y_j∂_{ŷ_j}, применяем (*).
(a) DΦ DŴ_Y DΦ^{-1} = Q(S DŴ_Y S^{-1})Q^{-1}. Элемент (j, i) матрицы DŴ_Y (компонента
j ∈ J, производная по блоку i) равен O(r^e), а по r — O(r^{e−1}). После сопряжения
(j, i) умножается на s_j/s_i, (j, r) — на s_j. Получаем O(r^{e+w_j−w_i}) ≤ O(r^{e−(w_k−w_j)})
и O(r^{e+w_j−1}). Оба o(1) по определению J.
(b) D²Φ[Ŵ_Y, e_i] = Σ_{j∈J}r^eY_j ∂_{ŷ_j}∂_iΦ. Для блока i это O(r^e s_j s_i/r); после
умножения на строку O(1/s_i) получаем O(r^{e+w_j−1}). Для i = r это O(r^e s_j/r)·O(1).
Всё o(1).

**Итог.** DA^x = P_ω + P_{T_0} + Σ w_iP_{N_i} + o(1), так что sym DA ⪰ ½I при малом ρ'.
Далее |V^x| ≤ C r, |W^x| ≤ C r^{1+e}, откуда |A| ≤ C|x| (на карте |x| ≍ r, так как
|Γ| → 1). ∎

## 5. Связь с теоремой B и границы

- Теорема B: блоки угловой (w = 1) и нормальный (w = 3/2); после сдвига η e = 1, и J
  содержит все блоки и r (так как 3/2 − 1 < 1). (Reg) — это лемма 4, D_J ≥ γ². Поле
  здесь немного другое (W с χ и без нормировки на m+1), но оценки те же.
- Без сдвига e = 1/2 и J = {нормальный}: (Reg) требует |∂_ν̂ f| ≥ c_0 там, где
  |f| ≤ c_0. Это нарушается при ν̂ = 0, g(ω) = 0, так что нужен подрежим (трубка
  вокруг луча) и лемма о склейке.
- Лемма R локальна. Чтобы получить поле на всём {U<0}, нужны покрытие режимами и
  склейка (`toolkit.md`, лемма G, гипотеза П).
