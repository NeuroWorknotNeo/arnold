# Набор инструментов: режимы, коррекция по тонким направлениям, склейка

vlad-claude, 27.09.2026, ход 6. Здесь обобщаются теорема B (`theoremB-proof.md`) и
эксперименты с пограничным случаем (`theoremC-draft.md`). Цель — свести тотальную
неустойчивость (и тем самым (A)) к **комбинаторно-геометрическому утверждению о покрытии**
множества {U<0} около 0 конечным числом «режимов».

Статусы: лемма 1 — [Доказано] (theoremB-proof.md §1). Лемма R — [Эскиз]: оценки те же,
что в §5 теоремы B, с заменой масштабов. Лемма G — [Эскиз]. Гипотеза П — [Гипотеза].

## 0. Критерий
Лемма 1: пусть на окрестности X = {U<0} ∩ B_ρ задано C¹-поле A, |A| ≤ M,
sym DA ⪰ 0 и A(U) ≤ pU (p > 0). Тогда 0 тотально неустойчива.
Достаточно даже sym DA ⪰ −δ, если p ≥ 2δ + ε (ослабленный критерий, palamodov2020.md).

## 1. Карта режима
Режим — это данные (Φ, w, K, F, d, e):
- Φ(r, ŷ) = r Γ(ŷ, r^{1/N}), ŷ = (ŷ_0, ŷ_1, …, ŷ_k) — блоки координат (ŷ_0 — «угловые»),
  Γ(ŷ, ε) = G(ŷ_0, (ε^{a_i} ŷ_i)_{i≥1}, ε), G ∈ C³, a_i = N(w_i − 1),
  1 = w_0 < w_1 < … < w_k — **масштабы**: блок i имеет евклидов размер s_i = r^{w_i}
  (радиус: s = 1·r, угловой блок: r).
- Условие ортогональности: при ε = 0 столбцы D_{ŷ_0}Γ, D_{ŷ_i}Γ/ε^{a_i} и радиальный вектор
  Γ(ŷ, 0) задают попарно ортогональные подпространства, в сумме дающие ℝⁿ. Тогда
  D Φ = Q · diag(1, r, s_1, …, s_k), где Q и Q^{-1} ограничены, и
  DV^x = Q Λ Q^{-1} + O(r^{1/N}), Λ = diag(1, 1, w_1, …, w_k). Это симметричная форма,
  ⪰ I (при ортогональности блоков); здесь V = r∂_r.
- Разложение: U∘Φ = r^d ( F(ŷ) + r^e H(ŷ, r^{1/N}) ), d > 0, e > 0, H ∈ C² вплоть до
  r = 0; K — компакт в ŷ-пространстве (область режима).

## 2. Лемма R (режим) [Эскиз]
Пусть J — множество блоков j, для которых **w_k − w_j < e** (всегда содержит самый тонкий
блок k; радиальное направление считается блоком с весом 1). Пусть на K выполнено
  (Reg)  |F| ≥ c_0  или  |∇_J F| ≥ c_0,
где ∇_J — градиент F по ŷ-переменным блоков из J. Тогда на Φ((0,ρ) × K°) поле
  A = V + W,  W = −χ(F) · U₊ · ∇^{sc}_J U / |∇^{sc}_J U|²,  U₊ = V(U) − dU,
удовлетворяет A(U) ≤ (d/2)U на {U<0}, sym DA ⪰ ½ I и |A| = O(|x|). Здесь χ = 1 при
|F| ≤ c_0/2 и χ = 0 при |F| ≥ c_0, а ∇^{sc}_J — градиент по блокам J в масштабированной
метрике (блок j с весом s_j²).

*Почему.* Там, где χ < 1, выполнено |F| ≥ c_0/2, значит |U| ≥ c_0r^d/4, а
|U₊| = O(r^{d+e}), так что A(U) = dU + (1−χ)U₊ ≤ (d/2)U. Компонента W по блоку j имеет
евклидов размер s_j r^e, её производная по блоку i даёт элемент DA порядка
s_j r^e / s_i. Он велик, только если блок i тоньше j больше чем на e, что исключено
определением J. Производные по r и вторые производные Φ — как в §5 теоремы B.
**Здесь нет условия β > α_max − 1 теоремы C:** «толстые» компоненты коррекции
просто не используются. Цена — условие (Reg): там, где F = 0, производная по тонким
блокам не должна обращаться в нуль.

Частные случаи:
- Теорема B: блоки (угловой, нормальный w = 3/2), после сдвига e = 1 > 1/2 = w_k − w_0,
  так что J — все блоки, и (Reg) есть лемма 4.
- Без сдвига (e = 1/2) было бы J = {нормальный}, и (Reg) нарушается в точках ν̂ = 0,
  g = 0. Там нужен более мелкий режим — трубка вокруг луча.

## 3. Лемма G (склейка) [Эскиз]
(a) **Одинаковые веса.** A_1 = V + W_1, A_2 = V + W_2 на пересечении двух режимов с
одним и тем же V; A = χA_1 + (1−χ)A_2. Выпуклая комбинация сохраняет A(U) ≤ pU. Ошибка
(W_1 − W_2) ⊗ ∇χ мала, если χ зависит только от переменных блоков не тоньше тех, по
которым направлены компоненты W_1 − W_2 (элемент s_j r^e / s_i).
(b) **Разные веса (переход по логарифмической шкале).** V_1 = Σ w_i y_i∂_i,
V_2 = Σ w'_i y_i∂_i в общих адаптированных координатах; χ = χ(log|y_j|/log r).
Ошибка Σ_i (w_i − w'_i) y_i ∂_i ⊗ ∇χ даёт элементы (i, j) порядка
(s_i/s_j) · χ'/|log r|. Она мала, если **w_i = w'_i для всех блоков i, более толстых,
чем y_j** (переход идёт по самой толстой из меняющихся координат). P = d(w) меняется
вместе с весами, но лемма 1 требует лишь P ≥ p > 0, поэтому поле **не нормируют** на P.
Проверено в эксперименте k4_perp.py (переход от главной трубки к трубке вокруг луча).

## 4. Гипотеза П (покрытие) [Гипотеза]
Для вещественно-аналитического U с U(0) = 0 множество {U<0} ∩ B_ρ покрывается конечным
числом режимов, удовлетворяющих (Reg), и переходов между ними типа G(a)/(b).
Из гипотезы П и лемм 1, R, G следует гипотеза Паламодова (тотальная неустойчивость), а
значит и (A).

Где тут должна работать аналитичность: в существовании конечного покрытия (разрешение
особенностей и конечность многогранников Ньютона после адаптированных замен) и в
разложениях с H ∈ C² вплоть до r = 0 (конечная определённость каждого режима). Для
C^∞-потенциала с плоской струёй (Пенлеве, Уренья) конечного покрытия нет.

Проверенные случаи покрытия:
- u_m невырождена (теорема 3 Паламодова): один режим, K — сфера, e = 1, J — всё.
- Теорема B: один режим (плюс трубка вне N_C, где U > 0).
- Пограничный пример k = 4 (q⁴ + xz⁸ + Kq·yz⁶): главная трубка (J = {нормальный}),
  область без коррекции, трубка вокруг луча (веса 4/3, 4/3) и переход G(b). Проверено
  только численно [Эксперимент].
