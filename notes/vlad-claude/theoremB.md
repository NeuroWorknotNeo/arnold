# Кандидат «теорема B»: главная часть — нестрогий минимум с гладким конусом нулей (Морс–Ботт)

vlad-claude, 27.09.2026. Статус: **[Эскиз]**, подробное доказательство пишется.

## Формулировка
U вещественно-аналитична около 0 ∈ Rⁿ, U = u_m + u_{m+1} + …, где
(B1) u_m ≥ 0 (значит, m чётно), Z = {u_m = 0} — конус, Σ = Z ∩ S^{n−1} — гладкое
    компактное подмногообразие сферы;
(B2) u_m невырожден поперёк Z (Морс–Ботт): для z ∈ Σ гессиан D²u_m(z) положительно
    определён на нормальном пространстве N_zZ;
(B3) g = u_{m+1}|_Σ имеет 0 регулярным значением на Σ.
Тогда 0 тотально неустойчива. Если g где-то отрицательна, то 0 не минимум, и равновесие
неустойчиво по Ляпунову.

## Почему это не покрыто известным (проверить!)
- Паламодов, теорема 3 (∇u_m ≠ 0 вне 0) — нет: ∇u_m = 0 на Z. Теорема 5 — это m = 2,
  когда Z — линейное подпространство. Теорема 6 (квазиоднородная невырожденная главная
  часть в линейных координатах) — нет: конус искривлён.
- Burgos arXiv:2506.19135, негенерический (non-generic) критерий, ньютоновский случай:
  нужно u_{m+1} < 0 на Σ. Но u_m чётна ⇒ Z = −Z, а u_{m+1} нечётна ⇒ на Σ она принимает
  значения обоих знаков (или ≡ 0). **Этот критерий в ситуации (B1)–(B2) не срабатывает
  никогда**, а (B3) — как раз общий случай.
- Kozlov–Palamodov (теорема 1): нужно, чтобы u_m не имел минимума, — нет.
- Alva–Garcia 2017 (класс 𝓗, условие (H3) Четаева на замыкании компоненты {j^sU<0}): на
  примере ниже (H3) нарушается в точках Σ, где g = 0.
- Maffei–Moauro–Negrini: нужно расщепление ‖q_1‖² + π_s(q_2) — нет.

## Пример
n = 3, U = (x² + y² − z²)² + x z⁴. [Доказано, элементарно]: 0 — изолированная
критическая точка (разбор случаев y = 0 и q = 0, где q = x²+y²−z²), не минимум
(U < 0 около конуса при x < 0), выполнены (B1)–(B3): g = cos θ/(√2)⁵ на двух окружностях Σ,
нули при θ = ±π/2 регулярны.

## Схема доказательства
1. Трубка: вне N_C = {d(x) ≤ C|x|^{3/2}} имеем U > 0 (так как u_m ≥ c|x|^{m−2}d²).
2. Координаты на N_C∖0: x = z + ν, z ∈ Z, ν ∈ N_zZ (ближайшая точка конуса;
   однородно степени 1). Параметрическая лемма Морса (однородная по растяжениям):
   u_m(z + ν) = Q_z(ν'), ν' = ν + O(|ν|²/|z|). Сдвиг ν' ↦ ν' + c(z)|z|² убирает член
   u_{m+1}, линейный по ν'.
3. Веса: z — 1, ν' — 3/2. Главная часть F = Q_z(ν') + G(z), G = u_{m+1}|_Z, взвешенной
   степени m+1. Остаток U − F — ряд из членов взвешенной степени ≥ m + 2 (проверено по
   биградуировке u_k(z+ν) ~ r^{k−j}ν^j, степень k + j/2; члены степени m + 1/2 и
   m + 3/2 обнуляются шагами 2).
4. На N_C∖0 ∇F ≠ 0: при ν' = 0 F = G, радиальная производная (m+1)G ≠ 0 при G ≠ 0, а
   при G = 0 касательная производная ≠ 0 по (B3).
5. Поле A = V/(m+1) + A_∞, V = z∂_z + (3/2)ν'∂_{ν'} (в евклидовых координатах
   sym DV = I + ½P_N + O(|x|^{1/2}) ⪰ ½I), A_∞ = −U₊R/(1 + R(v)) по Паламодову
   (теорема 6), R — взвешенно-нормированный градиент F, U₊ = V(U)/(m+1) − U.
   Тогда A(U) = U. Оценки масштабированием: A_∞ взвешенной степени 1, поэтому элементы
   DA_∞ в евклидовых координатах равны O(|x|^{1/2}) (самый плохой блок — z-компонента,
   ν-производная). Без шага 2 этот блок был бы O(1) — там ловушка.
6. Критерий (L') [palamodov2020.md]: sym DA ⪰ 0, P = 1 ⇒ тотальная неустойчивость.

Что проверить в подробном тексте: однородность и гладкость ν' и сдвига вне 0; равномерность
оценок в трубке; сходимость рядов; A ограничено.
