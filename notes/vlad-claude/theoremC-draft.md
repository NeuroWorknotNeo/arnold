# Черновик: «теорема C» — критерий трубки вокруг гладкого конуса с несколькими поперечными весами

vlad-claude, 27.09.2026, ход 4. Статус: **[Эскиз]**. Доказательство повторяет §4–§5
theoremB-proof.md с заменой масштабов; ждёт итогов ревью теоремы B.

## Данные
- Σ ⊂ S^{n−1} — гладкое компактное подмногообразие, Z — конус над ним, N → Σ —
  нормальное расслоение к Z (N_ω ⊥ T_ωZ = Rω ⊕ T_ωΣ).
- **Ортогональное** разложение N = N_1 ⊕ … ⊕ N_k на гладкие подрасслоения и веса
  1 < α_1 < … < α_k (рациональные, α_i − 1 = a_i/N).
- L_C = {ℓ = (ω, ν̂_1, …, ν̂_k): |ν̂| ≤ C} и отображение
  Φ(r, ℓ) = r Γ(ℓ, r^{1/N}), где Γ(ℓ, ε) = G(ω, (ε^{a_i} ν̂_i)_i, ε), G ∈ C³,
  G(ω, 0, 0) = ω, D_{μ_i}G(ω, 0, 0) = J_i(ω): N_i → N_ω — изоморфизмы на
  попарно ортогональные образы, в сумме дающие N_ω.
  (Так выглядят «нормальные формы»: в теореме B G(ω, μ, ε) = ω + ν(ω, μ − ε²η(ω)).)

## Условия
(C1) Φ — C²-диффеоморфизм (0,ρ) × L_C на образ T_C, и {U<0} ∩ B_ρ ⊂ Φ((0,ρ) × L_{C/2}).
(C2) U∘Φ = r^d ( f(ℓ) + r^β h(ℓ, r^{1/N}) ), d > 0, h ∈ C² по (ℓ, ε) вплоть до ε = 0, и
     **β > α_k − 1**.
(C3) d² f² + |∇f|² > 0 на L_C.

## Вывод
Поле A = r∂_r/d − U₊R/(1+R(W)), R = (d f r∂_r + ∇f)/(r^d (d²f² + |∇f|²)),
удовлетворяет A(U) = U и
  DA^x = (1/d)(P_T + Σ α_i P_{N_i}) + O(r^{β − (α_k − 1)}) + O(r^{1/N}),
значит sym DA ⪰ I/(2d) около 0, и по лемме 1 точка 0 тотально неустойчива.

## Где нужны условия
- Ортогональность образов J_i: DV^x ≈ Q Λ Q^{-1}, Λ = diag(1, 1, α_i). Симметрична, только
  если блоки ортогональны; иначе при сильно различных α_i форма может быть неопределённой.
- β > α_k − 1: элемент (ω, ν̂_k) матрицы D A_∞ после масштабирования имеет порядок
  r^{1 − α_k} · r^β. При β = α_k − 1 он O(1) — это ровно проблема линейного по ν члена в
  теореме B (там её снял сдвиг η).

## Граница метода (наблюдение)
Поперечный порядок k ≥ 4 при c = 1: u_m = r^{m−k}ν^k·φ, нормальная форма ν' = νφ^{1/k}
существует, α = 1 + 1/k. Член r^m L(ω) ν из u_{m+1} даёт превышение ровно 1/k = α − 1,
то есть пограничный случай. Сдвигом его не убрать: сдвиг даёт члены ν^{k−1}η. Нужен
другой приём (касательный сдвиг вдоль Z там, где ∇_Σ g ≠ 0?) или дополнительное условие
L ≡ 0.

## Склейка режимов внутри трубки (эскиз, n = 2 и трубки с c = 1)
Пример U = y⁴ − x³y² + x⁷: режимы y ~ x^{3/2} (грань 1), x² ≪ |y| ≪ x^{3/2} (вершина,
U ≈ −x³y²), y ~ x² (грань 2). Поля: A_1 = E_{3/2} + коррекция (P = 6),
A_v = x∂_x + α(τ) y∂_y, τ = log|y|/log x, α: 3/2 → 2 (P = 3 + 2α; **x-компоненту не
нормировать**, иначе ∂_y(1/(3+2α))·x ~ x/(y log) велико), A_2 = E_2 + коррекция.
Склейка A_1 и A_v по ŷ = y/x^{3/2} даёт ошибку (A_∞)⊗∇χ = O(r^{β+1−α}) — то же условие
β > α − 1. Переход по τ внутри вершины даёт ошибку O(1/log(1/r)).

## Пограничный случай на примере [Эксперимент]
`experiments/vlad-claude/fields/thmC_k4_example.py`, `thmC_k4_K.py`:
U = q⁴ + x z⁸ + K q x z⁶, q = x² + y² − z² (m = 8, k = 4, α = 5/4). Поле
A = V/9 − U₊R/(1+R(W)) без сдвига (линейный по σ член имеет пограничное превышение 1/4),
mpmath 80 знаков, 80 случайных точек {U<0} на каждом масштабе:
- K = 0: min λ(sym DA) ≈ 0.10 при r = 1e-2 … 1e-8 (коэффициент линейного члена мал);
- K = 5: ≈ 0.09;
- K = 50: ≈ −0.28 при r = 1e-16 … 1e-32 (предел отрицателен, но > −1/2, поэтому
  ослабленный критерий (L') с P = 1 ещё выполняется: нужно λ_min > −P/2);
- K = 200: ≈ −1.55, K = 1000: ≈ −8.3 при r = 1e-24 — не выполнен и (L').
Уменьшение θ-компоненты R ничего не меняет (−0.3335 при cθ = 1e-2, 1e-4). Значит,
условие β > α − 1 в теореме C — не артефакт оценки: у этой конструкции пограничный член
действительно портит монотонность. Для k ≥ 4 нужна другая конструкция поля (касательная
перепараметризация? поле, не близкое к взвешенному полю Эйлера?).
Это хороший тестовый пример для доски: n = 3, u_m ≥ 0 с гладким конусом нулей, (B3)
выполнено, но поперечный порядок 4.

## Разбор пограничного примера и план исправления (ход 4) [Эскиз]
Отладка (`k4_debug.py`, `k4_fix.py`, `k4_fix_debug.py`): при K = 200 плохой элемент sym DA
— сначала (радиальный, нормальный) ≈ 1.7. Он идёт от r-компоненты R: R_r ~ 1/(d f) около
критических точек f с f ≠ 0. Если убрать r-компоненту и оставить коррекцию только около
{f=0}, плохим становится (θ, нормальный) ≈ −1.4 около нулей g при малом σ̂. Причина
общая: коррекция B должна решать B(F) = −(β/d)·r^d·ε L(θ) σ̂ (ε = r^{1/4}), а в x-единицах
∂_σ B_θ ~ L/g' = O(1).

Разбиение на режимы, в каждом из которых ошибка мала (ε = r^{1/4}):
1. |σ̂| ≥ δ: чисто нормальная коррекция B_σ̂ = −εL/(4d·∂_σ̂f)·(…) ~ εL/σ̂³. Её вклад в DA
   равен O(εL/δ³), то есть мал.
2. |σ̂| < δ, |g(θ)| ≥ δ': коррекция не нужна: |f| ≥ δ'/2, и V(U)/d = U + U₊ с
   |U₊| ≲ εLδ·r^9 ≪ |U|, так что A(U) ≤ pU при A = V/d.
3. Промежуточный режим r^{1/3} ≪ |t| ≪ δ' (t = θ − θ_0, g(θ_0) = 0): около f = 0 имеем
   σ̂ ≈ (−g_1 t)^{1/4}, нормальная коррекция даёт ошибку εL/σ̂³ ~ εL/|t|^{3/4}. Она мала при
   |t| ≫ ε^{4/3} = r^{1/3}.
4. Трубка вокруг луча θ_0 (|t| ≲ K r^{1/3}): веса (1; 4/3 по касательной и нормали, то
   есть поперечно изотропно), грань σ̂⁴ + g_1 τ̂ + L_0 σ̂ невырождена (∂_τ̂ = g_1 ≠ 0).
   Пограничные члены r^{m+1}g_2t² и r^m L_1 tσ убираются адаптированными координатами:
   t' = g(θ)/g_1 и t'' = t(1 + (L_1/g_1)σ/r) — почти ортогональная замена. После этого
   работает теорема C.
Склейка 3↔4 по τ̂ = t/r^{1/3} и 1↔2 по σ̂ даёт малые ошибки (по той же логике
масштабов). Общий принцип: **пограничные члены лечатся переходом к более мелкому
режиму, в котором они входят в грань.** Реализовать численно — следующий шаг.
