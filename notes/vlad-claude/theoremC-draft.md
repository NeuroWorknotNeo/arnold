# Черновик: «теорема C» — критерий трубки вокруг гладкого конуса с несколькими поперечными весами

vlad-claude, 27.09.2026, ход 4. Статус: **[Эскиз]**. Доказательство повторяет §4–§5
theoremB-proof.md с заменой масштабов; ждёт итогов ревью теоремы B.

## Данные
- Σ ⊂ S^{n−1} — гладкое компактное подмногообразие, Z — конус над ним, N → Σ —
  нормальное расслоение к Z (N_ω ⊥ T_ωZ = Rω ⊕ T_ωΣ).
- **Ортогональное** разложение N = N_1 ⊕ … ⊕ N_k на гладкие подрасслоения и веса
  1 < α_1 < … < α_k (рациональные, α_i − 1 = a_i/N).
- L_C = {ℓ = (ω, ν̂_1, …, ν̂_k): |ν̂| ≤ C} и отображение
  Φ(r, ℓ) = r Γ(ℓ, r^{1/N}), где Γ(ℓ, ε) = G(ω, (ε^{a_i} ν̂_i)_i, ε), G ∈ C³,
  G(ω, 0, 0) = ω, D_{μ_i}G(ω, 0, 0) = J_i(ω): N_i → N_ω — изоморфизмы на
  попарно ортогональные образы, в сумме дающие N_ω.
  (Так выглядят «нормальные формы»: в теореме B G(ω, μ, ε) = ω + ν(ω, μ − ε²η(ω)).)

## Условия
(C1) Φ — C²-диффеоморфизм (0,ρ) × L_C на образ T_C, и {U<0} ∩ B_ρ ⊂ Φ((0,ρ) × L_{C/2}).
(C2) U∘Φ = r^d ( f(ℓ) + r^β h(ℓ, r^{1/N}) ), d > 0, h ∈ C² по (ℓ, ε) вплоть до ε = 0, и
     **β > α_k − 1**.
(C3) d² f² + |∇f|² > 0 на L_C.

## Вывод
Поле A = r∂_r/d − U₊R/(1+R(W)), R = (d f r∂_r + ∇f)/(r^d (d²f² + |∇f|²)),
удовлетворяет A(U) = U и
  DA^x = (1/d)(P_T + Σ α_i P_{N_i}) + O(r^{β − (α_k − 1)}) + O(r^{1/N}),
значит sym DA ⪰ I/(2d) около 0, и по лемме 1 точка 0 тотально неустойчива.

## Где нужны условия
- Ортогональность образов J_i: DV^x ≈ Q Λ Q^{-1}, Λ = diag(1, 1, α_i). Симметрична, только
  если блоки ортогональны; иначе при сильно различных α_i форма может быть неопределённой.
- β > α_k − 1: элемент (ω, ν̂_k) матрицы D A_∞ после масштабирования имеет порядок
  r^{1 − α_k} · r^β. При β = α_k − 1 он O(1) — это ровно проблема линейного по ν члена в
  теореме B (там её снял сдвиг η).

## Граница метода (наблюдение)
Поперечный порядок k ≥ 4 при c = 1: u_m = r^{m−k}ν^k·φ, нормальная форма ν' = νφ^{1/k}
существует, α = 1 + 1/k. Член r^m L(ω) ν из u_{m+1} даёт превышение ровно 1/k = α − 1,
то есть пограничный случай. Сдвигом его не убрать: сдвиг даёт члены ν^{k−1}η. Нужен
другой приём (касательный сдвиг вдоль Z там, где ∇_Σ g ≠ 0?) или дополнительное условие
L ≡ 0.

## Склейка режимов внутри трубки (эскиз, n = 2 и трубки с c = 1)
Пример U = y⁴ − x³y² + x⁷: режимы y ~ x^{3/2} (грань 1), x² ≪ |y| ≪ x^{3/2} (вершина,
U ≈ −x³y²), y ~ x² (грань 2). Поля: A_1 = E_{3/2} + коррекция (P = 6),
A_v = x∂_x + α(τ) y∂_y, τ = log|y|/log x, α: 3/2 → 2 (P = 3 + 2α; **x-компоненту не
нормировать**, иначе ∂_y(1/(3+2α))·x ~ x/(y log) велико), A_2 = E_2 + коррекция.
Склейка A_1 и A_v по ŷ = y/x^{3/2} даёт ошибку (A_∞)⊗∇χ = O(r^{β+1−α}) — то же условие
β > α − 1. Переход по τ внутри вершины даёт ошибку O(1/log(1/r)).
