# Склейка через максимум выпуклых функций: критерий тотальной неустойчивости без ошибок склейки

vlad-claude, 27.09.2026. Статусы помечены у каждого утверждения.

## Мотивация
Ошибка Burgos (arXiv:2108.05829v4, лемма 2.2) — в склейке локальных полей разбиением
единицы: член Σ (V_p − V_q) ⊗ ∇f_p имеет порядок O(1) и знака не имеет
(см. burgos-review.md). Если брать **градиентные** поля V = ∇φ и склеивать не суммой, а
**максимумом** функций φ_i, ошибки склейки не возникает: в точках переключения у max
выпуклый излом. Этого хватает, потому что вдоль траектории нужна лишь выпуклость
функции t ↦ φ(x(t)).

Похожий приём уже есть у Паламодова (ФАН 11:4, 1977, основная лемма): поле v
**непрерывное и C¹ вне конечного числа кривых** с <v, u'> ≤ 0 и <v'ξ, ξ> ≥ c|ξ|². Здесь
поле даже не обязано быть непрерывным.

## Лемма M (критерий) [Доказано]
Пусть U ∈ C² в шаре B = B_ρ(0), U(0) = 0, X = {x ∈ B : U(x) < 0}. Пусть O_1, …, O_k —
открытые множества и φ_i ∈ C²(O_i) — функции со свойствами:

(M1) *корректность максимума:* каждая точка x ∈ X лежит хотя бы в одном O_i, функция
φ(x) := max{φ_i(x) : O_i ∋ x} ограничена на X, и для каждого j, каждой точки
x ∈ X ∩ ∂O_j и каждой последовательности O_j ∋ y_n → x выполнено
limsup φ_j(y_n) < φ(x), а φ непрерывна на X. (Функция перестаёт быть активной до края
своей области.)

(M2) *локальная выпуклость и толчок:* найдётся p > 0 такое, что для всех i и всех x ∈ X ∩ O_i,
в которых φ_i активна (φ_i(x) = φ(x)), выполнено
  D²φ_i(x) ⪰ 0   и   <∇φ_i(x), ∇U(x)> ≤ p·U(x);
(M3) |∇φ_i| ≤ L на O_i ∩ X.

Тогда любое движение ẍ = −∇U(x) с энергией E < 0, для которого x(t) ∈ B при t ∈ [0, T],
удовлетворяет оценке
  T ≤ ( L v + √(L² v² + 4 p|E| ‖φ‖_∞) ) / (p|E|),   v := √(2(E − min_B̄ U)).
В частности, 0 тотально неустойчива, и если 0 не минимум, равновесие неустойчиво по Ляпунову.

**Доказательство.** Пусть x(t) ∈ B при t ∈ [0, T]. Так как |ẋ|²/2 = E − U ≥ 0, имеем
U(x(t)) ≤ E < 0, т.е. x(t) ∈ X. Положим g(t) = φ(x(t)), g_i(t) = φ_i(x(t)) (там, где
x(t) ∈ O_i). Зафиксируем t_0 и I = {i : x(t_0) ∈ O_i, φ_i(x(t_0)) = φ(x(t_0))}.
Для j ∉ I либо x(t_0) ∉ Ō_j, либо x(t_0) ∈ O_j и φ_j(x(t_0)) < φ(x(t_0)), либо
x(t_0) ∈ ∂O_j и по (M1) limsup φ_j < φ(x(t_0)). В любом случае, по непрерывности φ и x(t),
в некоторой окрестности J точки t_0 функция φ_j либо не определена в x(t), либо
строго меньше g(t). Значит, на J g = max_{i ∈ I} g_i. Для i ∈ I
  g_i''(t) = ẋᵀ D²φ_i(x) ẋ + <∇φ_i(x), ẍ> = ẋᵀ D²φ_i(x) ẋ − <∇φ_i(x), ∇U(x)>,
и в точке t_0 (где φ_i активна) по (M2) g_i''(t_0) ≥ −p U(x(t_0)) ≥ p|E|. g_i'' непрерывна,
значит для любого η > 0 после сужения J имеем g_i'' ≥ p|E| − η на J для всех i ∈ I. Максимум
конечного числа (p|E| − η)-выпуклых функций (p|E| − η)-выпукл, т.е.
h_η(t) = g(t) − (p|E| − η)t²/2 выпукла на J. Выпуклость — локальное свойство: h_η выпукла
на [0, T] при каждом η > 0, а значит и h_0 выпукла. Отсюда
  g(T) ≥ g(0) + g'_+(0) T + p|E| T²/2,
где g'_+(0) ≥ min_{i ∈ I(0)} <∇φ_i, ẋ(0)> ≥ −L v. Так как |g| ≤ ‖φ‖_∞, получаем
p|E| T²/2 − L v T − 2‖φ‖_∞ ≤ 0, откуда оценка на T. ∎

Замечания.
1. Вариант в духе Паламодова 1977: если D²φ_i ⪰ c I (c > 0) и <∇φ_i, ∇U> ≤ 0 на активных
   множествах, а 0 — изолированная критическая точка (тогда |∇U| ≥ δ(E) > 0 на
   {U ≤ E} ∩ B̄), то функции φ_i − σU при малом σ удовлетворяют аналогу (M2) на
   {U ≤ E}: D² ⪰ (c − σ‖D²U‖) I ⪰ 0, <∇(φ_i − σU), ∇U> ≤ −σδ(E)². Активные множества
   не меняются (сдвиг на одну и ту же функцию). Доказательство то же.
2. Условия (M2) линейны по φ_i, и ни на что за пределами активного множества не
   налагаются. Поэтому вся трудность **локализуется**: нужны лишь «хорошие» выпуклые
   функции на каждом «режиме» и правильное расположение активных множеств.

## Пример: градиентное поле в теореме 3 Паламодова [Доказано]
Пусть U вещественно-аналитична, U = u_m + O(|x|^{m+1}), m ≥ 2, ∇u_m ≠ 0 при x ≠ 0. Тогда
  φ(x) = |x|²/2 − K |x|^{3−m} U(x)
при достаточно большом K и малом ρ удовлетворяет (M2) с одной функцией (k = 1) и p = m/2.

Доказательство. По однородности и компактности сферы |∇u_m(x)| ≥ 2c_0|x|^{m−1}, значит
|∇U| ≥ c_0|x|^{m−1} при малых |x|. Кроме того, |U| ≤ C|x|^m, |∇U| ≤ C|x|^{m−1},
‖D²U‖ ≤ C|x|^{m−2}, а <x, ∇U> = mU + r_1, где |r_1| ≤ C_1|x|^{m+1}
(так как <x, ∇u_k> = k u_k). Далее
  ∇φ = x − K|x|^{3−m}∇U − K(3−m)|x|^{1−m} U x,
  <∇φ, ∇U> = mU + r_1 − K|x|^{3−m}|∇U|² − K(3−m)|x|^{1−m} U <x, ∇U>
         ≤ mU + C_1|x|^{m+1} − K c_0²|x|^{m+1} + K C_2 |x| |U|.
При K = C_1/c_0² и |x| ≤ m/(2KC_2) получаем <∇φ, ∇U> ≤ (m/2) U на {U < 0}.
Гессиан: D²(|x|^{3−m}U) = |x|^{3−m}D²U + ∇|x|^{3−m} ⊗ ∇U + ∇U ⊗ ∇|x|^{3−m} + U D²|x|^{3−m};
каждое слагаемое по норме ≤ C|x|. Значит, ‖D²φ − I‖ ≤ KC|x| ≤ 1/2 при малых |x|.
Наконец, φ = O(|x|²) и ∇φ = O(|x|) ограничены. ∎

(Поле Паламодова A = E/m − U_+R/(1+R(v)) не градиентное; здесь градиентное, с P = m/2
вместо 1.)

## Что дальше
- Локальная задача: для «режима» (карты разрешения) найти выпуклую φ с
  ∇φ(log|U|) ≥ p на U^- в этом режиме. Для мономиального Ũ = ±w^d это одно скалярное
  неравенство Σ d_i ∇φ(w_i)/w_i ≥ p, а не n равенств, как у поля Эйлера карты. Поэтому
  градиентность не должна сильно мешать. [Гипотеза]
- Расположение активных множеств: «горбы» вида ε·(взвешенная квадратичная форма)×χ(координата
  карты) имеют ограниченный гессиан (проверено на карте t ~ s^a, a ≥ 1), поэтому ими
  можно делать нужную функцию активной в своём режиме. [Эскиз]
- Трудное место: около нулей главной части внутри режима нужен «толчок» −K β U с
  β, согласованным с масштабом режима. Оценка гессиана βD²U и сравнение с β|∇U|²
  требуют анизотропных оценок (аналог теоремы 6). Здесь, видимо, и должна работать
  аналитичность (Лоясевич), а в гладком случае всё ломаться (пример Уреньи).
