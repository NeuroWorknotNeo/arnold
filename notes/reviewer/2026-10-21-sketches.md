## 1. `n2-sketch.md` (гипотеза П при n = 2)

**Метки.** Весь текст — [Эскиз]. Метка соответствует содержанию: это схема, а не доказательство.

### 1.1. Ложное утверждение: «U приведена»

Текст: «0 — изолированная критическая точка. Отсюда U **приведена**: кратный множитель f² даёт
∇U = 0 на {f = 0}». Рассуждение верно, только если вещественное множество {f = 0} содержит
что-то кроме 0. Если f неприводим и {f = 0} ∩ ℝ² = {0}, противоречия нет.

Контрпримеры (проверено в sympy, `n2_reduced.py`; вещественная критическая точка только 0, и 0
не минимум):
- U = x(x² + y²)²;
- U = x((y − x²)² + x⁶)². Ветви y = x² ± i x³ — **комплексные и двукратные**, с вещественным
  старшим членом. В трубке около ω_0 = (−1, 0) многочлен грани веса 2 равен −(ŷ − 1)⁴, то есть
  у него вещественный корень кратности 4. Значит, ложна и фраза из пункта «Конечность»: «ветви
  {U = 0} (и комплексные) — различные ряды Пюизё».

**Вывод о конечности при этом верен, но обосновать его нужно иначе.** Пусть цепочка кратных
вещественных корней бесконечна. Тогда кратность с какого-то шага постоянна (μ ≥ 2), усечения
сходятся к вещественному ряду Пюизё φ, а φ — корень U кратности ≥ 2. Значит, вещественная кривая
y = φ(x), x > 0, состоит из критических точек, и это противоречит изолированности. Нужна
y-регулярность в координатах трубки (подготовка Вейерштрасса): она достигается общей линейной
заменой. Вне этого места изолированность в эскизе не используется. Более того, она здесь
и не нужна: кратную вещественную ветвь можно «выпрямить» аналитической заменой y' = y − φ(x), и
карта (x, φ(x) + x^w ŷ) имеет вид, нужный лемме R. Значит, в эскизе работает аналитичность
(конечность многоугольников, сходимость рядов Пюизё, H ∈ C²), а изолированность работает только
в неверно обоснованном месте.

### 1.2. Склейка при n = 2: перечисленный пробел фактически закрывается

Автор называет пробелом «аккуратную лемму G(b) для семейства режимов в переходной зоне». Но при
n = 2 **все** переходы проходят через вершинные зоны:
- переход от радиального режима к трубке идёт через вершину (m − μ_0, μ_0) с α = 1;
- переход от грани w к грани w' идёт через вершину между ними;
- переход от родителя к подрежиму идёт через вершину (d − wμ, μ) нового многоугольника. Грани
  потомка имеют вес > w: точки с j > μ на прямой веса w лежат выше вершины.

В вершинной зоне U = c x^a y^b (1 + o(1)) равномерно. Это стандартная оценка сходящегося ряда:
отношение монома к вершинному не превосходит δ^{|j−b|}. Поэтому для A = x∂_x + α(u) y∂_y
(в сдвинутых координатах) A(U) = (a + αb)U(1 + o(1)), а sym DA = diag(1, α) + O(1/|log x|) +
O(x^{w−1}). Последнее слагаемое — вклад кривизны координат y' = y − ŷ_0x^w. Если взять α(u)
постоянной у концов вершинного интервала, а c_0 в лемме R меньше min|F| на воротнике ∂K (тогда
χ(F) = 0 и W = 0 на перекрытиях), то поля на перекрытиях **совпадают**, и лемма G при n = 2 не
нужна вовсе.

### 1.3. Неназванные пробелы (все, по-моему, устранимы)

1. Обоснование конечности (п. 1.1).
2. Выбор c_0 так, чтобы поправка W обращалась в нуль у края K. Без этого склейка соседних режимов
   не тривиальна.
3. Равномерное доминирование вершинного одночлена в вершинной зоне для бесконечного ряда, в
   сдвинутых координатах.
4. Нижний край, когда y ∤ U (вершина (a, 0), U ≈ c x^a), не упомянут. Тривиально, но для
   полноты покрытия нужен.
5. «Поле x∂_x + W y∂_y при большом W» в нижнем крае: большое W не нужно, годится любое α, в том
   числе w_last. Зачем «большое», не объяснено.
6. Оценка sym DA в декартовых координатах для вложенных сдвигов: члены O(x^{w−1}) от
   ∂_x(ŷ_0 x^w). В тексте сказано только, что карта «ортогональна асимптотически».
7. Покрытие без щелей (назван автором): при n = 2 он закрывается выбором δ (грань) < δ_v
   (вершина).

### 1.4. По пунктам задания

- Кратные корни граней разобраны: подрежимы, поле родителя инвариантно (проверил: x∂_x + w y∂_y
  = x∂_x + w y'∂_{y'} при y' = y − ŷ_0x^w).
- Ветви на осях разобраны («нижний край»); случай y² | U исключён изолированностью, а без неё
  разбирается так же.
- Конечность: вывод верен, аргумент неверен (п. 1.1).
- Переходы G(b) — только в вершинных зонах, там всё верно (п. 1.2).
- Склейка разных рогов: трубки около разных ω_0 ∈ Σ не пересекаются, с радиальным режимом
  трубка склеивается при α = 1. Это верно.
- Изолированность используется только в «U приведена», то есть неверно. Нужна она, только если
  не выпрямлять кратные вещественные ветви.

### 2.1. Сама «теорема C»: верна (как следствие леммы R)

Оценка DA^x = (1/d)(P_T + Σα_iP_{N_i}) + O(r^{β−(α_k−1)}) + O(r^{1/N}) согласуется с §4 леммы R.
У коррекции есть компоненты во всех блоках, размера s_j r^β. Элемент (j, i) имеет порядок
r^{β + w_j − w_i}, и худший случай j = радиальный или угловой, i = самый тонкий. Отсюда ровно
β > α_k − 1. Более того, теорема C — частный случай леммы R: при β > α_k − 1 множество J состоит
из всех блоков и r, а (C3) на компакте L_C даёт (Reg). Недочёты записи:
- в формуле A = r∂_r/d − U₊R/(1+R(W)) символ W не определён; по смыслу знаменатель — R(U)
  (тогда A(U) = U);
- P_T должно означать P_ω + P_{TΣ}.

### 2.2. «Граница метода»

Верно. Я пересчитал: сдвиг ν → ν + δ, убирающий линейный член, требует δ ~ r^{k/(k−1)}. Он
порождает член ν^{k−1}δ с превышением 1/(k(k−1)) < 1/k, то есть ещё хуже исходного. Уточнение:
при нечётном k форма u_m меняет знак на Z и условие (C1) не выполняется, так что «k ≥ 4» значит
«чётное k ≥ 4». С леммой R пограничность сама по себе не мешает: J = {нормальный}, а (Reg)
нарушается только при ν̂ = 0, g = 0. Это согласуется с toolkit.

### 2.3. Числа пограничного примера (K-развёртка)

### 3.1. G(a) — верно при условиях, которые названы не все

Выкладка верна. Выпуклая комбинация сохраняет A(U) ≤ min(p_1, p_2)U на {U<0} и sym DA ⪰ ½I, а
ошибка (W_1 − W_2) ⊗ ∇χ имеет порядок s_jr^e/s_i ≤ r^e, если χ зависит от блоков не тоньше j.
Молча предполагается:
- **одно и то же V в двух картах.** Поле V = r∂_r зависит от карты Φ. Для двух разных карт с
  одинаковыми весами это надо проверять (при n = 2 это верно по построению сдвигов, в общем
  случае нет);
- оба поля верны на всём перекрытии, и перекрытие содержит воротник фиксированной ширины в
  переменных ŷ, иначе ∇χ не O(1/s_i).

### 3.2. G(b) — главный неназванный пробел

Оценка V-части верна: элемент (i, j) равен (s_i/s_j)χ'/|log r|, а при w_i = w'_i для блоков
толще y_j он O(1/|log r|). Не названо следующее.
1. **Переходная зона не покрыта ни одним режимом леммы R.** Срезка χ(log|y_j|/log r) живёт на
   интервале фиксированной длины по u, а режим леммы R с компактом K в ŷ покрывает по u интервал
   длины O(1/|log r|). Поэтому в переходной зоне нужно поле с **переменными весами** V_α,
   α = α(u), для которого надо доказать A(U) ≤ pU и sym DA ⪰ ½I, с коррекцией. Это отдельная
   «лемма R с переменными весами», и её нет. При n = 2 зона вершинная, и всё тривиально
   (п. 1.2). При n ≥ 3 это не так: режим 3 из theoremC-draft — ровно такая зона, U там не
   доминируется одночленом, и именно там численно отказывает поле хода 5. Этот пробел верно
   назван в n2-sketch, но в toolkit его нет.
2. Член (W_1 − W_2) ⊗ ∇χ в G(b) не оценён.
3. «Общие адаптированные координаты» — предположение. В разборе k = 4 у соседних режимов разные
   замены (t', t'' в режиме 4).
4. G(b) рассматривает одну переходную переменную. Переходы через страты коразмерности ≥ 2
   многогранника Ньютона, где веса меняются сразу по нескольким переменным, не рассмотрены.
5. Ошибка O(1/|log r|) асимптотически мала, но с большими константами работает только на
   нефизически малых r (ср. п. 2.5).

### 3.3. §4: «П + леммы 1, R, G ⇒ гипотеза Паламодова ⇒ (A)»

Вторая импликация верна: если 0 не минимум, точки с U < 0 есть сколь угодно близко к 0, и
движение из такой точки с нулевой скоростью имеет h < 0 и уходит. Первая верна **только при
усиленной гипотезе П**. В формулировке П «переходы типа G(a)/(b)» не определены, а молча
предполагается следующее.
1. Каждый режим удовлетворяет всем условиям леммы R: (O), (Φ), разложение с H ∈ C² и (Reg) на K,
   с запасом K ⊂ K̃°.
2. Каждое перекрытие — либо G(a) (то же V, воротник), либо G(b) (общие координаты, одна
   переходная переменная, **поле верно на всей переходной зоне**, п. 3.2.1).
3. Кратность перекрытий ограничена, и есть разбиение единицы, производные которого
   одновременно удовлетворяют условиям масштабов. Тройные перекрытия (луч внутри трубки внутри
   радиального режима) в G не разобраны.
4. Склеенное поле класса C¹: этого требует лемма 1. Эксперимент k4_perp это условие нарушал.
5. Константы равномерны: p = min d_i/2, а суммарная ошибка склеек < запаса ½.

Пока этого нет, правильный статус вывода такой: «[Эскиз] импликации из [Гипотеза] П». Из
неупомянутого ещё: П сформулирована без изолированности. Это согласуется с формулировкой
гипотезы Паламодова в `problem/KNOWN_RESULTS.md` («всякая точка равновесия», по P20; с
первоисточником я не сверял). Но тогда вся аналитическая содержательность сидит в П, а леммы 1,
R, G аналитичность не используют. Это честно сказано в разделе «Где тут должна работать
аналитичность».

В списке «Проверенные случаи покрытия» пункт «Пограничный пример k = 4 … Проверено только численно
[Эксперимент]» опирается на ошибочный код (п. 2.5), и проверялось там другое поле. Пункт надо
снять или переформулировать. «Для C^∞ … конечного покрытия нет» — следствие от противного только
для примеров, где тотальная неустойчивость ложна (Уренья), и только при доказанной импликации. Само
по себе это не доказано.

## 4. `example13-proof.md` §5

**Что верно.** Описание примера 13 в терминах леммы R верно: блоки «радиальный + угловой»
(масштаб r) и «нормальный» (масштаб r²), e = 1, J = {нормальный}, (Reg) нарушается при η = 0,
G = 0. Угловая поправка Z_2 = −κ'(∂_φU/s⁶)∂_φ в этом примере работает: её вклад в V(U) равен
−κ'(∂_φU)²/s⁶ ≤ 0, а вклад в Sym DV — O(κ'), что видно в лемме 6. Константы леммы 6 проверил
численно: max|G''| = 2.736 ≤ 3, max|a_1'| = 0.75. Ключевое и **не названное** в §5 обстоятельство:
производная Z_2 по нормали ограничена только потому, что у Ũ_0 = 4η² + G/8 **нет смешанного
члена φ–η**. Тогда ∂_d(∂_φU/s⁶) берётся из O(s)-части (a_1'), и ρ∂_d f_2 = a_1'/√2 + O(s).

**Предложенное обобщение ложно в заявленной форме.** Текст: «(Reg) можно ослабить до … или
|∇_{J'}F| ≥ c_0 по толстым блокам J', для которых s_j r^e/s_i = O(1), с поправками по J' с малыми
фиксированными коэффициентами». В общем случае элемент DA от такой поправки равен
κ'(s_j/s_i)∂_{ŷ_i}∂_{ŷ_j}F + κ'(s_jr^e/s_i)∂_{ij}H. Условие s_jr^e/s_i = O(1) контролирует только
второе слагаемое. Первое равно κ'r^{−(w_i−w_j)}∂_{ij}F и неограниченно, если ∂_{ij}F ≢ 0.

Контрпример (`ex13_cross.py`, `ex13_cross2.py`): U_b = U_13 + b·Q·z²·x, b = 0.1. Тогда
F = 4η² + (b/√2)cosφ·η + G/8. Ослабленное (Reg) выполнено: min(F² + F_η² + F_φ²) ≈ 0.0039 > 0 на
сетке, и s_jr^e/s_i = r·r/r² = 1. Но поле V из §4 с теми же κ = 1/100, κ' = 1/50 даёт на {U<0}
λ_min(Sym DV) = −0.27, −4.59, −47.9 при s = 1e-3, 1e-4, 1e-5, то есть рост как 1/s; при b = 0
λ_min ≈ 0.16.

Как исправить: добавить условие ∂_{ŷ_i}∂_{ŷ_j}F ≡ 0 для всех j ∈ J' и всех блоков i тоньше j
(F расщепляется), либо сначала сделать адаптированную замену. Здесь годится
d' = d + (b/(8√2))cosφ·s², то есть «жёлоб надо искать» из §7. Отдельно не разобран случай, когда
в J' попадает радиальный блок (w_k − 1 = e).

**Что не доказано:** общее утверждение целиком, включая совместимость J'-поправки с локализацией
χ(F) леммы R и запас ½ − O(κ'). Метка [Эскиз] при «Вероятно … Проверено только на этом примере»
завышена: по содержанию это [Гипотеза].
