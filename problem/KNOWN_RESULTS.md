## 1. Формулировка задачи

- В «Задачах Арнольда» задача 1971-4 цитируется так:
  «Prove the instability of the equilibrium 0 of the analytic system
  $\ddot x = -\partial U/\partial x$ in the case where the isolated critical point 0 of the
  potential U is not a minimum» [[BMP21]](#BMP21). **[А]** Здесь «Arnold's Problems»,
  Springer 2004 [[Arn04]](#Arn04); русское издание — «Задачи Арнольда», ФАЗИС, 2000.
- В постановке нашей доски это «ещё более узкий частный случай (A)» задачи 1971-4. Точный
  русский текст и комментарии в книге (кто писал, какие результаты упомянуты) **пока не
  сверены** — это открытый пункт для участников.
- Корни вопроса — у Ляпунова: он ставил обращение теоремы Лагранжа для аналитических
  потенциалов (гипотеза: изолированное равновесие без минимума потенциала неустойчиво).
  **[В]**

## 2. Классические результаты: неустойчивость при отсутствии минимума

| Работа | Утверждение | Метка |
|---|---|---|
| Лагранж (1788), Дирихле (1846) | Строгий минимум $U$ ⇒ равновесие устойчиво. | [П] |
| Ляпунов (1892) | Если отсутствие минимума видно уже по квадратичной части $U_2$ (она принимает отрицательные значения), равновесие неустойчиво. Если $U$ имеет максимум, определяемый младшей формой $U_m$, — тоже. | [П] |
| Четаев | Для однородного потенциала без минимума равновесие неустойчиво (метод функций Четаева). | [П] |
| Hagedorn (1971) [[Hag71]](#Hag71) | Если младшая ненулевая форма $U_m$ ряда Тейлора принимает отрицательные значения, равновесие неустойчиво. Строгий локальный максимум гладкого потенциала неустойчив при любой гладкой кинетической энергии. | [П]; второе — [В] |
| Taliaferro (1980) [[Tal80a]](#Tal80a) | Неустойчивость максимумов потенциала (обращение теоремы Лагранжа–Дирихле для максимумов). | [В] |
| Taliaferro (1980) [[Tal80b]](#Tal80b) | Устойчивость для **двумерных аналитических** потенциалов. Точная формулировка не установлена. | [В] |
| Kozlov (1979–1986) [[Koz81]](#Koz81), [[Koz86]](#Koz86); статья в Int. J. Non-Linear Mech. (1979) [[NLM79]](#NLM79) | Метод асимптотических траекторий. Пример [NLM79]: если ряд Маклорена имеет вид $V_2 + V_m + V_{m+1} + \dots$ и $V_2 + V_m$ не имеет локального минимума, существует траектория, асимптотическая к равновесию. Для $n = 2$ и аналитического $U$ без минимума — неустойчивость (Козлов, 1981). | [NLM79] — [А]; остальное — [В]/[П] |
| Kozlov, Palamodov (1982) [[KP82]](#KP82) | Об асимптотических решениях уравнений классической механики. Точная формулировка не установлена. | [В] |
| Hagedorn, Mawhin (1992) [[HM92]](#HM92) | Простой вариационный подход к обращению теоремы Лагранжа–Дирихле. | [А] (название) |
| Moauro, Negrini; статья в J. Appl. Math. Mech. (1993) [[AMM93]](#AMM93) | Обращение для $C^h$-потенциала, $h > 3$, если отсутствие минимума потенциала видно по младшим ненулевым членам разложения. В работе $U$ — силовая функция, то есть минус потенциал, поэтому там сказано «отсутствие максимума». Метод — инвариантные устойчивые многообразия. | [А] |
| Garcia, Tal (2003) [[GT03]](#GT03) | $n = 2$: если джет $U$ некоторого порядка $k$ показывает, что минимума нет, существует асимптотическая траектория, и равновесие неустойчиво. | [А] |
| Alva, Garcia (2017) [[AG17]](#AG17) | Если отсутствие минимума видно по джету, то для большого класса систем равновесие неустойчиво и есть асимптотическая траектория (модификация результата Красовского). | [А] |

Смысл этих работ: неустойчивость доказана, когда отсутствие минимума «видно» по конечной
части ряда Тейлора: по младшей форме, по квазиоднородной части или по многограннику Ньютона
в удобных координатах. Для $n = 2$ аналитический случай, по-видимому, разобран полностью:
Козлов, Taliaferro, для нестрогих минимумов — Laloy–Peiffer. **[В]** При $n \ge 3$
трудность — ситуации, где отрицательные значения $U$ сосредоточены вдоль искривлённых
направлений, невидимых для младших форм.

## 3. Контрпримеры в гладком классе

| Работа | Пример | Метка |
|---|---|---|
| Painlevé (1904), Wintner | $n = 1$, $U(x) = e^{-1/x^2}\cos(1/x)$: $0$ не минимум, но равновесие устойчиво. Критические точки накапливаются к нулю — **не изолирована**. | [А] |
| Laloy (1976) | $n = 2$, $U(x,y) = e^{-1/x^2}\cos(1/x) - e^{-1/y^2}(\cos(1/y) + y^2)$: более тонкий гладкий контрпример. | [А] (формула по вторичному источнику) |
| Ureña (2020) [[Ure20]](#Ure20) | Гладкий $U$ на $\mathbb R^2$ с **изолированным строгим максимумом**, у которого есть последовательность периодических орбит, сходящихся к равновесию. Значит, в гладком классе нет «полной» неустойчивости (в смысле Зигеля–Мозера), хотя по Ляпунову максимум неустойчив. | [А] |

Нам **не известен** гладкий пример **изолированной** критической точки без минимума с
устойчивым по Ляпунову равновесием. Есть ли такой пример — отдельный содержательный вопрос.
Пример Уреньи показывает, что «полная неустойчивость» требует аналитичности.

| Burgos, Maderna, Paternain (2021) [[BMP21]](#BMP21) | Неустойчивость, когда локальный минимум $U$ достигается на гиперповерхности. Покрывает аналитические случаи, недоступные критериям по младшему джету. | [А] |
| Burgos, Paternain (2021) [[BP21]](#BP21) | Критерий неустойчивости нестрогого минимума: существование гладкого решения некоторого линейного уравнения в частных производных, построенного по лагранжиану. | [А] |

| Brunella (1998) [[Bru98]](#Bru98) | У аналитического векторного поля на $\mathbb R^3$ с изолированной особой точкой $0$ есть траектория, стремящаяся к $0$ в прошлом или в будущем. Методы: десингуляризация векторных полей в размерности три и индексные соображения типа Пуанкаре–Хопфа. Применяется к случаю двух степеней свободы (поток на трёхмерном уровне энергии). | [А] |

## 5. Полная неустойчивость: гипотеза Паламодова и заявленное доказательство

- **Полная неустойчивость** (формулировка по [[B21]](#B21), [А]): у каждой точки $x_0$ есть
  окрестность $W$ и положительная функция $T$ на $(-\infty, U(x_0))$ такие, что любое
  движение с энергией $E < U(x_0)$, начавшееся в $W$, проводит внутри $W$ не больше времени
  $T(E)$.
- **Почему отсюда следует (A).** Пусть $0$ не минимум. Возьмём $x$ сколь угодно близко к
  нулю с $U(x) < U(0)$ и нулевую начальную скорость. Энергия движения $E = U(x) < U(0)$,
  поэтому оно за конечное время покидает фиксированную окрестность $W$. Значит, равновесие
  неустойчиво. Изолированность критической точки здесь даже не нужна. Нестрогие минимумы
  этим рассуждением не охватываются: возле них нет энергий ниже $U(0)$.
- **Паламодов (1977)** [[P77]](#P77). Основная лемма: если на $U^-_\rho$ есть непрерывное поле
  $v$, гладкое вне конечного числа кривых, с $\langle v, u'\rangle \le 0$ и
  $\langle v'\xi,\xi\rangle \ge c|\xi|^2$, то равновесие неустойчиво. Такое поле строится при
  $n = 2$, если $u$ аналитична или бесконечно дифференцируема с конечнократной
  критической точкой. **[Т]** (прочитаны первые пять страниц; двумерная конструкция
  через угол между $-x$ и $u'$). В [P20] это называется тотальной неустойчивостью при
  $n = 2$.
- **Паламодов (2020)** [[P20]](#P20), обзор. **[Т]** (прочитан полностью, `vlad-claude`,
  конспект — `notes/vlad-claude/palamodov2020.md` в ветке `participant/vlad-claude`).
  - Определение 1 (тотальная неустойчивость) и **Гипотеза 1**: всякая точка равновесия
    аналитического потенциала тотально неустойчива.
  - **Теорема 2** (из [P77], критерий поля): если на $X = \{U < U(x_0)\} \cup \{x_0\}$ есть
    $C^1$-поле $A$ такое, что (I) форма $\langle \xi, \nabla_\xi A\rangle$ в точке $x_0$
    неотрицательна и (II) $\inf_X A(U)/U > 0$, то $x_0$ тотально неустойчива.
    Доказательство — рост функции $F = \langle \dot x, A\rangle$.
  - **Теорема 3**: $U = u_m + u_{m+1} + \dots$, $\nabla u_m \ne 0$ при $x \ne 0$ ⇒ тотальная
    неустойчивость. **Теорема 5**: то же для ограничения на ядро квадратичной части.
    **Теорема 6**: квазиоднородная главная часть без критических точек вне нуля и остаток
    $O(|x|\,|x|_w)$. Пример 3 — неквазиоднородный $U$, для которого поле подобрано вручную.
  - Отмечено: для аналитических систем общего вида (не натуральных) асимптотического
    движения может не быть (Козлов–Трещёв, 2018).
  Этим кругом результатов пользуются Allaire и Rauch в работах о теореме Ирншоу. **[В]**
- **Burgos (2021), отозвано** [[B21]](#B21). Препринт заявлял «впервые подробное
  доказательство гипотезы Паламодова о полной неустойчивости». Из него следовали бы
  гипотеза Ляпунова–Арнольда и сведение аналитического обращения теоремы
  Лагранжа–Дирихле к нестрогим минимумам. Версии v1 (12.08.2021) … v4 (11.09.2021). В v5
  (16.07.2022) препринт **отозван**: ошибка во втором слагаемом последнего равенства
  леммы 2.2 (не та асимптотика), на неё указал Паламодов. **[А]** Схема [B21]: монализация
  Хиронаки идеала $\mathfrak m_{x_0}(U)$, поля Эйлера $\sum w_i\partial_{w_i}$ в картах,
  склейка разбиением единицы и затем теорема 2. Разбор ошибки — в
  `notes/vlad-claude/burgos-review.md` (ветка `participant/vlad-claude`, [Доказано], ждёт
  проверки). Оценка $\langle v,\nabla_v V\rangle = (1+o(1))|v|^2$ ложна уже в одной карте:
  для седла $U = x(y-3x)$ поле карты равно $x\partial_x + (2y-3x)\partial_y$, и форма
  $v_1^2 - 3v_1v_2 + 2v_2^2$ знаконеопределена. Член склейки $v(f_p)\langle v, V_p\rangle$
  имеет порядок $O(|v|^2)$, а не $o(|v|^2)$.
- **Burgos (2025/2026)** [[B25]](#B25). Полная неустойчивость генерична в аналитическом
  классе электромагнитных лагранжевых систем при слабом магнетизме. Метод — адаптация
  раздутия Макги (McGehee). **[А]** Опубликовано в J. Differential Equations. **[А]**
  По TeX v1 **[Т]**:
  - во введении дословно: «Arnold proposed the problem of instability of an isolated
    non-minimum critical point of a real analytic potential in Newtonian mechanics. Even
    this simplified version of the Lagrange-Dirichlet converse remains open»;
  - критерий (Prop. total_inst_criterion_0): если $f = u_{l}|_{S^{n-1}}$ (младшая форма на
    сфере) — функция Морса и $0$ — её регулярное значение, то точка тотально неустойчива;
  - негенерический критерий, ньютоновский случай: тотальная неустойчивость, если вторая
    ненулевая однородная часть $U_{l_2}$ отрицательна во всех критических точках $f$ с
    $f \le 0$;
  - автор пишет, что все известные ему критерии, кроме этого, требуют, чтобы $0$ было
    регулярным значением $f$.
  Доказательства этих критериев доской не проверялись.

## 6. Что это значит для доски

1. Случай (A) при $n \ge 3$ **открыт** (по доступным данным). Это настоящая
   исследовательская задача, а не проверка чужого результата.
2. Два естественных входа: понять, почему не работает лемма 2.2 [B21] и что уцелело из
   подхода Burgos и Паламодова; и искать своё доказательство методами §2 и §5,
   начиная с частных классов.
3. Для **многочленов** доступны эффективные средства. Показатель Лоясевича в неравенстве
   $|\nabla U| \ge C|U|^{\rho}$ для многочлена степени $d$ от $n$ переменных не больше
   $1 - R(n,d)^{-1}$, где $R(n,d) = d(3d-3)^{n-1}$ (D'Acunto–Kurdyka) [[DK05]](#DK05)
   **[А]**. Кроме того, изолированность и неотрицательность проверяются алгоритмически.
   Это делает полиномиальный вариант (A) удобным для независимого доказательства.
4. Независимо от этого открыты:
   - неустойчивость **нестрогих** минимумов в аналитическом классе при $n \ge 3$ (общий
     случай);
   - вопрос о гладком контрпримере для изолированной критической точки (§3).
