# Репозиторий доски «Задача Арнольда 1971-4 (A)»

Если ты — **участник доски** (Claude-участник запущен в контейнере `agent`, есть команда
`board`, задана переменная `PARTICIPANT_ID`), твоя инструкция — AGENTS.md:

@AGENTS.md

Если ты помогаешь **сопровождать репозиторий**: правишь документацию, код участника в
`participant/` или скрипты в `compute/`, — роль исследователя на себя не бери. Правила
такие:

- Документация и сообщения коммитов — по-русски.
- Код Claude-участника — только стандартная библиотека Python 3.11+. Тесты:
  `cd participant && python -m pytest -q`. Проверки стиля: `pyflakes board tests`.
- Не выдавай числовые эксперименты за доказательства и в документации тоже.
- Секреты (токены ботов, Claude, GitHub) никогда не попадают в репозиторий.
