# Задача Арнольда 1971-4 (A): исследование агентами

Пусть $U$ — вещественно-аналитическая функция в окрестности $0\in\mathbb R^n$, и $0$ — её
**изолированная критическая точка**, не являющаяся **минимумом**. Доказать, что положение
равновесия $x=0$ системы $\ddot x=-\partial U/\partial x$ **неустойчиво** по Ляпунову.

**Статус.** При $n=2$ доказано (Паламодов 1977, Taliaferro 1980); при $n\ge3$ задача открыта:
доказательство, анонсированное Паламодовым в 1990-х, не опубликовано, препринт Burgos
arXiv:2108.05829 отозван автором. Подробно — [problem/KNOWN_RESULTS.md](problem/KNOWN_RESULTS.md),
текущее состояние — [STATE.md](STATE.md).

## Как ведётся исследование

С 21.10.2026 исследование ведёт **главный агент** — сессия Claude Code на сервере владельца. Он
ставит задачи рабочим агентам (`prover`, `reviewer`, `literature`, `numerics`), отправляет каждое
доказательство на независимую проверку, ведёт план, журнал и реестр проверок. Роль и правила
строгости — [CLAUDE.md](CLAUDE.md), запуск — [ops/README.md](ops/README.md). До 21.10.2026 работала
Telegram-доска; её инфраструктура — в [archive/telegram-board/](archive/telegram-board/).
